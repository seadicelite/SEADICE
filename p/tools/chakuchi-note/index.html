Chakuchi Note / Attachment-Aware Journal

不安定な関係パターンで消耗する自分から、安定した関係を築ける自分へ。

「また同じパターンで疲れてしまった」——人間関係の消耗は、多くの場合その場限りの相性ではなく、繰り返されるパターンによるものです。愛着ノートは、愛着理論（アタッチメント理論）に基づき、日々の関係性のやり取りをAIと一緒に記録・分析するアプリ。1回の診断で終わらせず、小さな記録を積み重ねることで、少しずつ安定した関わり方に近づきます。

人間関係でいつも同じパターンに消耗してしまう人、診断だけでは物足りなかった人向けのアプリです。

診断で終わらせず、日々の記録で変えていく

愛着スタイル診断は自分のパターンを知るきっかけにはなりますが、「知って終わり」になりがちです。愛着ノートは、実際に人間関係で起きた出来事——不安になった瞬間、距離を置きたくなった瞬間、安心できた瞬間——をそのつどAIに伝えることで、自分のパターンをその場で言語化し、次に取れる小さな行動を提案します。診断結果を実生活の記録に落とし込むことで、少しずつ関わり方を変えていきます。

アプリの機能

AI関係性分析

関係性の中で起きた出来事をAIに伝えると、その裏にある愛着パターンと次の一歩を提案します。

安定行動の記録

いつもと違う、安定した関わり方ができたら記録し、積み上げていきます。

関係性ログ

過去の出来事とAI分析を振り返り、自分の関係パターンを可視化します。

継続ストリーク管理

安定した関わり方ができた連続日数をひと目で確認できます。

パターンに気づき、少しずつ変えていく。
