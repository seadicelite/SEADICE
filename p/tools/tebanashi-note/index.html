Tebanashi Note / Expressive Writing

抱えたままの自分から、書いて手放せた自分へ。

言葉にできないモヤモヤ、誰にも話せない悩み、頭の中でぐるぐる同じことを考え続けてしまう夜。てばなしノートは、そんな感情をただ15分間書き出すだけの筆記開示（エクスプレッシブライティング）アプリです。誰かに見せる必要も、正解を出す必要もありません。書くこと自体が、心の荷物を軽くする最初の一歩になります。

悩みを言語化できずに抱え込みがちな人、話す相手がいない・話したくない人、頭の中で同じ考えがループしてしまう人向けのアプリです。

「話せばいい」がいちばん難しい

悩みは誰かに話せば軽くなると言われますが、話す相手がいない、うまく言葉にできない、話すこと自体が億劫という人は少なくありません。てばなしノートは、話す相手がいなくても一人でできる筆記開示という手法を採用し、15分間のタイマーと自由記述欄だけで、誰にも見せずに気持ちを整理できる場所を用意します。

アプリの機能

15分タイマー筆記

15分間、ただ書き続けるためのタイマーと全画面の記入欄。文章の巧拙は問いません。

書く手が止まった時の問い

何を書けばいいかわからない時に押せる「質問をもらう」ボタン。心理学的な筆記開示の問いかけをもとにした質問が届きます。

4日サイクル管理

研究で効果が示されている4日間の連続筆記をひとつのサイクルとして記録し、無理なく続けられます。

端末内だけの保存

書いた文章は端末内にのみ保存され、誰にも共有されません。安心して本音を書き出せます。

抱え込むのではなく、書いて手放す自分へ。
