Curiosity Type / 好奇心タイプ診断

マンネリな自分から、好奇心を行動に変えられる自分へ。

「毎日同じことの繰り返しで刺激がない」——そんな時、心理学の5次元好奇心理論をもとにAIがあなたの好奇心タイプを診断します。喜びの探求・謎解き探求・挑戦好き・人間観察・スリル探求の5タイプから自分の傾向を知り、タイプ別の「今日の小さな挑戦」で毎日に新しい刺激を取り戻します。

毎日がマンネリで新しい刺激が欲しい人、自分の好奇心の方向性を知って行動に活かしたい人向けのアプリです。

アプリの詳細を見る

「好奇心がない」のではなく、向きを知らないだけ

「最近何にも興味が持てない」と感じるとき、実は好奇心そのものが失われたわけではなく、自分に合った好奇心の方向性を知らないまま日々を過ごしていることがほとんどです。好奇心タイプ診断は、質問に答えるだけでAIがあなたの好奇心タイプを見極め、そのタイプに合った小さな挑戦を毎日提案します。理論だけで終わらせず、今日から行動できる形に変えるのがこのアプリの目的です。

アプリの機能

好奇心タイプ診断

15〜20問の質問に答えると、AIが5つの好奇心タイプからあなたの傾向を診断します。

4軸のAIアドバイス

理論・実践・継続・目的達成の4つの観点から、タイプに合った具体的な行動提案を受け取れます。

診断履歴

過去の診断結果を振り返り、自分の好奇心の変化を確認できます。

今日の小さな挑戦

診断タイプに合わせて、今日すぐ試せる小さな挑戦を毎日1つ提案します。

設定・カスタマイズ

フィードバック送信・不具合報告など、アプリを一緒に育てる導線を用意しています。
