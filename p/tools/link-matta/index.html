そのリンクちょっと待った
届いたリンクの危険度を、AIが開く前にチェック

「お荷物を持ち帰りました」「未払いがあります」。そんなSMSのリンクを押す前に、ちょっと待った。そのリンクちょっと待ったは、SEADICEが作っている無料のiPhoneアプリです。届いたリンクやQRコードを貼るか読むと、AIが行き先とメッセージの言い方を確かめ、危険度と「開いて大丈夫か」をひと目で伝えます。

開く前に、ちょっと待ったリンクやQRコードはすぐに開きません。AIが確かめてから、開くかどうかを選べます。
危険度をひと目で危険度を0〜100のメーターで出し、「開いて大丈夫そうです」「ちょっと待った」「開かないで」で伝えます。
メッセージごと貼れる「お荷物を持ち帰りました」のようなSMSを文ごと貼ると、AIが言い方の怪しさまで読みます。
QRコードも駐車場や飲食店のQRコードを、カメラか写真から読んで確かめます。
短縮URLの行き先bit.ly などの短縮URLは、ページを開かずに最後の行き先までたどってから判断します。
履歴は端末の中確かめたリンクは、このiPhoneの中だけに残ります。

3つの判定のあわせ技

AIだけに任せず、確かな情報とあわせて危険度を決めます。

  • 端末の中の点検: 詐欺の報告があるサイト5万件（毎日更新）、日本でよく見られているサイト約7万件、会社名（amazon・rakuten・sagawa など）を借りた偽ドメインや1文字だけ変えたつづり、短縮URL・番号だけのURL・「@」入りのURL・http・日本の会社がまず使わない末尾（.top・.cn など）
  • Googleの危険サイト情報（Web Risk）: マルウェアやフィッシングとして報告されたサイトか
  • AI（Claude）: 行き先と、貼ったメッセージの言い方を読んで、急がせる・不安にさせる手口かを判断し、ひとことで理由を伝えます

詐欺の報告があるサイトは、AIが低く言っても危険度90以上にします。AIに聞けないとき（圏外など）は、端末の中の点検だけで判断し、そのことを画面に書きます。

端末の中の点検は、JPCERT/CCが公開した日本のフィッシングURL 7,600件（2026年3〜5月）で、約5割に「危険」か「注意」、残りもすべて「初めて見るサイト」と出ました。「よく見られているサイト」と出たものは0件です（SEADICE調べ）。

試しに読めるコードはテスト用のQRコードにあります。

できないこと

  • 「開いて大丈夫そうです」は安全の保証ではありません。新しく作られたばかりの詐欺サイトを見逃すことがあります
  • 開いた先のページの中身（入力欄など）までは調べません
  • メッセージやメールを自動で見張ることはできません（自分で貼るか、QRコードを読みます）

詐欺の手口と見分け方は、SEADICEの防犯メディアで読めます。

こんな人におすすめ

  • 宅配業者・カード会社・携帯会社を名乗るSMSが届いて、本物か迷う
  • 離れて暮らす親に「変なリンクは、開く前にこれで確かめて」と渡したい
  • 駐車場や飲食店のQRコードで支払う前に、本物か確かめたい
  • 仕組みはよくわからないけれど、AIに見てもらえると安心できる

料金とプライバシー

  • 無料です。広告もアプリ内課金もありません。登録・ログインもありません
  • 確かめるURLと貼った文だけを判定サーバーに送ります。電話番号・メールアドレス・8けた以上の数字は送る前に伏せ、サーバーでは保存しません
  • 設定で「AIで確かめる」をオフにすると、何も送らずに端末の中だけで判断します
  • 履歴と設定は端末の中だけに保存されます。カメラの映像は保存も送信もしません

よくある質問

そのリンクちょっと待ったとは何ですか？

SEADICEが作っている無料のiPhoneアプリです。SMS・LINE・メールで届いたリンクや、駐車場・飲食店のQRコードを、開く前にAIが確かめます。危険度を0〜100で出し、「開いて大丈夫そうです」「ちょっと待った」「開かないで」のどれかで伝えます。

どうやって危険度を決めているのですか？

3つをあわせて決めています。1つ目は端末の中の点検（詐欺の報告があるサイト5万件、日本でよく見られているサイト約7万件、会社名を借りた偽ドメインや短縮URLなどの書き方）。2つ目はGoogleの危険サイト情報（Web Risk）。3つ目はAI（Claude）で、行き先と、貼ったメッセージの言い方（「至急」「お荷物を持ち帰りました」など）を読んで判断します。

送った内容は保存されますか？

保存しません。確かめるURLと、貼ったメッセージの文だけを判定サーバーに送ります。文の中の電話番号・メールアドレス・8けた以上の数字は、送る前に伏せます。サーバーは結果を返すだけで、記録も残しません。AIを使わない設定にすると、端末の中の点検だけで判断します。

「開いて大丈夫そうです」なら安全ですか？

安全の保証ではありません。新しく作られたばかりの詐欺サイトを見逃すことがあります。ログインや支払いは、公式アプリや自分で開いた公式サイトから入るのが確実です。

料金はかかりますか？

無料です。広告もアプリ内課金もなく、登録やログインもありません。

あわせて使える防犯アプリ

家族のための防犯フィルターは、Safariで詐欺サイトそのものを開けなくする拡張機能です。開く前に確かめるのがこのアプリ、開いてしまったときに止めるのが防犯フィルターです。
