退去立会いの写真記録

賃貸の部屋を、入居時と退去時に場所ごとに撮って並べておくツールです。「この傷は入居前からありました」と写真で示せるので、敷金が返ってくるか不安なまま立会いに行かなくて済みます。写真には日時が入り、比較レポートは印刷やPDF保存ができます。無料・登録不要で、写真は外部に送信されません。

2. 場所ごとに撮る

    写真はこのブラウザの中だけに保存されます。ブラウザのデータを消したり、長く開かなかったりすると消えることがあります。撮り終えたら上のボタンでPDFを保存し、入居時の分は管理会社にもメールで送っておくと安心です。

    その傷は誰の負担？ 早見表

    普通に暮らしてできた傷みや年数による劣化は貸主の負担で、借主が払うのは不注意や手入れ不足でできた傷・汚れだけです。国土交通省のガイドラインの例をもとにまとめました。

    状態負担
    家具を置いた跡の床・カーペットのへこみ貸主
    日当たりによる壁紙・畳の変色貸主
    冷蔵庫・テレビの裏の壁の黒ずみ（電気ヤケ）貸主
    ポスターやカレンダーの画びょうの穴貸主
    エアコン設置のビス穴・跡貸主
    次の入居者のための鍵の交換（紛失していない場合）貸主
    借主が掃除をした上での専門業者のクリーニング貸主
    重い物をかけるための釘・ネジ穴（下地の交換が必要なもの）借主
    タバコのヤニ・臭いで壁紙の張替えが必要なもの借主
    飲み物をこぼしたまま放置したシミ・カビ借主
    結露を放置して広がったカビ・シミ借主
    台所の油汚れ（手入れ不足によるもの）借主
    引越し作業でついた床の傷、ペットの傷・臭い借主

    契約書に「ハウスクリーニング代は借主負担」などの特約があり、金額が明記され内容に合意している場合は、特約が優先されることがあります。立会いの前に契約書を確認してください。

    壁紙の負担割合を計算

    借主の過失で壁紙（クロス）を張り替える場合でも、全額を払うとは限りません。ガイドラインではクロスの耐用年数を6年とし、6年たつと価値は1円になる考え方で負担割合を決めます。

    入居時に張り替えたばかりなら経過年数は0です。わからない場合は管理会社に「入居時に張替えをしたか」を聞いてください。この計算は目安で、通常の暮らしでできた汚れならそもそも負担は0です。カーペット・クッションフロアも同じ6年の扱いですが、畳表・ふすま紙・障子紙は消耗品として年数を考えません。

    立会い当日にやること

    1. 入居時の写真（このツールのPDF）を手元に用意し、指摘された箇所は入居時の写真と見比べてもらいます。
    2. 指摘箇所は退去時の写真も撮り、その場で「入居前からある」「通常の暮らしの傷み」と言える点を伝えます。
    3. 修繕費の金額に納得できないうちは、その場で書類にサインしません。「明細を見てから返事します」で問題ありません。
    4. 後日、場所・工事内容・単価・面積がわかる見積もりの明細を書面でもらいます。
    5. 納得できなければ、消費者ホットライン188で消費生活センターに相談します。請求額が60万円以下なら、原則1回の審理で終わる少額訴訟もあります。

    使い方

    1. 鍵を受け取った日、荷物を入れる前に「入居時」を選び、場所ごとに写真を撮ります。部屋全体の写真と、傷・汚れのアップの両方があると説得力が増します。
    2. 傷や汚れを見つけたら状態のチップを選び、メモに大きさや場所を書きます。
    3. 「比較レポートを印刷・PDF保存」でPDFにし、管理会社にメールで送って保管します。
    4. 退去の日、荷物を出した後に「退去時」に切り替えて同じ場所を撮ります。レポートでは入居時と退去時が左右に並びます。

    よくある質問

    原状回復は、借りた時の状態に戻すことですか？

    いいえ。国土交通省のガイドラインと民法621条では、経年変化や普通に暮らして生じた損耗（通常損耗）は借主が直す義務はなく、借主の不注意や通常の使い方を超えた傷・汚れだけを借主が負担するとされています。

    入居時の写真はいつ撮ればいいですか？

    荷物を運び込む前、鍵を受け取った当日が理想です。家具を置いた後では、床や壁の傷が入居前からあったことを示しにくくなります。撮った写真は管理会社にメールで送っておくと、送信日時が第三者の記録として残ります。

    写真に入る日時は何の日時ですか？

    写真ファイルに記録された日時です。その場で撮った写真なら撮影した日時になります。あとからアルバムの写真を選んだ場合は、端末によって保存日時になることがあるため、メールで送った日時などの記録もあわせて残してください。

    撮った写真はどこに保存されますか？

    お使いのブラウザの中だけに保存され、SEADICEのサーバーを含む外部には送信されません。ブラウザのデータを消すと写真も消えるため、記録が終わったら比較レポートをPDFで保存してください。

    退去費用の請求に納得できないときの相談先は？

    消費者ホットライン188に電話すると、最寄りの消費生活センターにつながります。請求額が60万円以下なら、原則1回の審理で終わる少額訴訟という手続きもあります。

    根拠にした資料

    国土交通省「原状回復をめぐるトラブルとガイドライン」（再改訂版） e-Gov法令検索民法 第621条（賃借人の原状回復義務）・第622条の2（敷金）
