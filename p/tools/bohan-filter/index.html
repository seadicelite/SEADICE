家族のための防犯フィルター
親や子どもを、詐欺サイトと広告から守る

家族のための防犯フィルターは、iPhoneのSafariに追加する無料の拡張機能つきアプリです。知られている詐欺サイトやにせログイン画面を開けなくし、広告や追跡も減らせます。Safariに入る前の入口、つまり駐車場や飲食店に貼られた偽のQRコードや、SMS・LINEで届いたリンクも、開く前に行き先を確かめられます。見たページや読んだ内容は、アプリにもSEADICEにも届きません。

見たページの情報が届かない仕組み

このアプリの拡張機能は、Appleの「コンテンツブロッカー」という仕組みを使っています。拡張機能の仕事は「行ってはいけないサイトのリスト」をSafariに渡すことだけで、止める判断はSafariが端末の中で行います。そのため、どのページを見たか・どこで止めたかは、アプリにもSEADICEにも届きません。

リストは、公開されている詐欺サイト・広告・追跡のリスト（Phishing.Database、AdGuard Japanese、EasyList、EasyPrivacy）をもとに、SEADICEが毎日作り直しています。変換の方法と出典は配信ページで公開しています。

QRコードとメッセージのリンクは、開く前に

Safariの拡張機能が働くのは、ページを開いたあとです。その前の入口になるのが、駐車場や飲食店に貼られた偽のQRコード（クイッシング）や、宅配業者・カード会社を名乗るSMS・LINEのリンクです。iPhoneの標準カメラでもQRコードは読めますが、行き先を小さく表示してそのまま開くだけで、本物かどうかは教えてくれません。防犯フィルターの「開く前に確かめる」は、開く前に次のことを確かめます。

  • 詐欺の報告があるサイトか（拡張機能と同じ Phishing.Database をもとに毎日作り直す5万件のリスト）
  • 日本でよく見られているサイトか（Chromeの利用統計の上位約7万ドメイン。新しく作られた偽サイトは、まずここに入りません）
  • URLに会社名（amazon・rakuten・paypay など）が入っているのに、公式のドメインではないか。つづりを1文字変えたもの（mizuha など）も見ます
  • 短縮URL・番号だけのURL・見た目の似た文字・「@」入りのURLなど、行き先を隠す書き方か
  • 暗号化されていない http の通信か、日本の会社がまず使わない末尾（.top・.cn など）か

照らし合わせは端末の中で行い、読んだURLはどこにも送りません。

JPCERT/CCが公開した日本のフィッシングURL 7,600件（2026年3〜5月）で試したところ、約5割に「危険」か「注意」が出て、残りもすべて「初めて見るサイト」と表示されました。「よく見られているサイト」と表示されたものは0件でした。正規サイト（.jp の上位3,000件）を「注意」にした誤りは0.5%でした（SEADICE調べ）。

試しに読めるコードはテスト用のQRコードにあります。

できないこと

  • 新しく作られたばかりの詐欺サイトは、リストに載るまで止められません。「開く前に確かめる」の「気になる点は見つかりませんでした」も、安全の保証ではありません
  • 電話・SMS・LINEのメッセージそのものは止められません（メッセージ内のリンクをSafariで開いたときに働きます）
  • Safariの設定から拡張機能を外されることは防げません（外れたときはアプリで確認できます）
  • 詐欺サイト・広告・追跡を止めるのは Safari だけです（Chromeなどでは働きません。「開く前に確かめる」はどのブラウザでも使えます）

詐欺の手口と見分け方は、SEADICEの防犯メディアで解説しています。

こんな人におすすめ

  • 離れて暮らす親が、偽のメールやSMSのリンクを開いてしまわないか心配
  • 駐車場や飲食店のQRコードで支払う前に、本物か確かめたい
  • 子どもに初めてiPhoneを持たせる
  • 「ウイルスに感染しました」のような警告画面や、偽の通販サイトから家族を守りたい
  • 広告ブロックは入れたいが、見たページを知られるのは嫌

料金とプライバシー

  • 無料です。広告もアプリ内課金もありません
  • 登録・ログインはありません
  • 設定や「止めないサイト」は端末の中だけに保存されます

よくある質問

家族のための防犯フィルターとは何ですか？

iPhoneのSafariに追加する、無料の拡張機能つきアプリです。知られている詐欺サイト・にせログイン画面を開けなくし、広告や追跡も減らせます。SEADICEが作っています。

見たページの情報は送られますか？

送られません。Appleのコンテンツブロッカーという仕組みで、ブロックするサイトのリストをSafariに渡すだけなので、どのページを見たかはアプリにもSEADICEにも届きません。

どんな詐欺でも止められますか？

いいえ。止められるのは、すでに見つかってリストに載っている詐欺サイトだけです。リストは毎日更新していますが、新しい詐欺サイトをすべて防ぐことはできません。

QRコードやSMSのリンクも確かめられますか？

はい。アプリのホームの「開く前に確かめる」で、カメラや写真からQRコードを読むか、届いたリンクを貼り付けると、開く前に行き先を点検します。詐欺の報告があるサイト・会社名を借りた偽ドメイン・短縮URLなどを知らせます。読んだ内容は端末の中で照らし合わせ、どこにも送りません。

子どもが勝手にオフにできますか？

アプリ内のスイッチは4桁の暗証番号でロックできます。ただし、Safariの設定から拡張機能そのものを外すことは防げません。外れたときはアプリのホームで確認できます。

料金はかかりますか？

無料です。広告もアプリ内課金もなく、登録やログインもありません。

Chromeやパソコンでも使えますか？

詐欺サイト・広告・追跡を止めるのは、iPhone・iPadのSafari専用です。「開く前に確かめる」はブラウザを問わず使えます。パソコンでは使えません。
