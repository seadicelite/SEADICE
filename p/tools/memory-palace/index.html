記憶の宮殿メイカー

頭の中に自分だけの宮殿を作り、AIと一緒に「場所法」で記憶する。

対象: 資格試験・語学学習でまとめて暗記したい人、スピーチ原稿を覚えたい人、物忘れが気になる人

こんな悩みはありませんか

単語カードを何度めくっても翌日には忘れてしまう。プレゼンの原稿を丸暗記しようとして本番で真っ白になる。買い物リストを覚えたつもりが半分抜けている——。こうした「覚えられない」悩みの多くは、記憶のやり方が合っていないだけです。人間の脳は無機質な文字の羅列より、慣れ親しんだ「場所」と「イメージ」を結びつけたほうが圧倒的に記憶に残りやすいことが、記憶術の世界で古代ギリシャの時代から知られています。

記憶の宮殿メイカーの機能

宮殿の作成

実在または想像の部屋を「宮殿」として登録し、玄関・棚・机など好きなだけポイント（場所）を配置できます。

記憶項目の配置

買い物リスト・スピーチの要点・単語・年号など、覚えたい項目を各ポイントに紐付けて配置します。

AIイメージ変換ヒント

覚えにくい項目をAIに送ると、印象的で忘れにくい関連付け・イメージのヒントを提案してくれます。

練習（巡る）モード

宮殿を順番に巡りながら項目を暗唱し、答え合わせで記憶の定着度をトレーニングします。

場所法の理論解説

なぜ場所と結びつけると記憶に残るのか。記憶術の理論をやさしい言葉で解説し、実践クエストで習得します。

「覚えられない自分」から「どんな量でも記憶の宮殿で覚えられる自分」へ。
