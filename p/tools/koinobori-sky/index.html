Koinobori Sky

An AI lifestyle app for overseas users that matches a described family and space to a real koinobori carp streamer set size, and explains its carp colors and pole accessories.

The Problem With This Niche

Koinobori usually reach people abroad as a single decorative windsock bought for a spring photo, with no sense of the size-grading system retailers use or the meaning behind each carp's color and position on the pole. First-time buyers regularly pick a set that's the wrong size for their space, or never learn that each carp is supposed to represent a specific family member.

Koinobori Sky fills that gap. You describe your children, your mounting space, and your region, and Claude AI, working from documented Kodomo no Hi tradition, matches you to a real set size and explains the meaning of every carp and accessory.

Key Features

01

One-line family description turned into an AI-matched koinobori set size

02

Matched from real sizes: 1.5m balcony pole up through 4m+ yagura ground sets

03

Genuine magoi, higoi, and kogoi carp-color meaning explained with each match

04

Real accessory pieces covered: fukinagashi windsock and yaguruma ornament

05

Daily free-match limit with rewarded-ad unlock
