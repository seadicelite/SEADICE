こまめ休憩タイマー

集中が続かないのは、意志が弱いからではありません。研究では、短い休憩を決まった間隔でこまめに挟むと集中を保ちやすいことがわかっています。作業と休憩を自動でくり返し、休憩中にやることも出す無料タイマーです。

使い方

  1. 作業と休憩の長さを選びます。迷ったら「10分＋90秒」から始めてください。
  2. スタートを押して作業します。時間になると音が鳴り、休憩に切り替わります。
  3. 休憩中は、表示された行動（伸びをする、水を飲むなど）か、作業と関係のない一瞬の課題をやってみます。
  4. 休憩が終わると、また作業が始まります。止めたいときは一時停止かリセットを押します。

なぜ短い休憩をこまめに取るのか

  • 集中力は30分前後で目減りし始めます。これは「資源切れ」ではなく、脳が同じ作業に慣れて注意を向けなくなる現象だと考えられています。
  • 数秒〜90秒の短い注意そらしを挟むだけで、集中の落ち込みを防げたという実験があります。
  • 好きなタイミングで休むより、決まった間隔で休むほうが疲労や気分の面で有利だったという報告もあります。
このツールの根拠になった記事集中が続かないのは意志の弱さじゃない。休憩の取り方を研究で調べた

よくある質問

なぜ10分ごとに90秒の休憩なのですか？

集中力は30分前後で目減りし始めますが、数秒〜90秒の短い注意そらしを挟むだけで集中の落ち込みを防げたという実験があります。長い休憩を1回取るより、短い休憩をこまめに取るほうが集中を保ちやすいと考えられています。

ポモドーロ・テクニック（25分＋5分）とどちらがいいですか？

研究では、決まった時間で区切って休む方法は、好きなタイミングで休む方法より疲労や気分の面で有利でした。どちらが正解というより、作業に合わせて続けやすいほうを選んでください。

休憩中にスマホを見てもいいですか？

根拠にした研究は数秒〜90秒の短い注意そらしを扱ったもので、SNSのように新しい情報が次々入る休憩の効果は検証されていません。伸びをする、水を飲む、窓の外を見るなど、作業に戻りやすい休憩がおすすめです。
