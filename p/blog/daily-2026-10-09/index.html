10月9日の開発日誌
— ホームページをピクトグラムに刷新、Hostingの容量上限で3回止まった日

2026-10-09 · SEADICE

2026年10月9日のSEADICEは、ホームページをピクトグラムのデザインに作り直し、ブラウザで使えるツールを3本増やした日だった。アプリ2本は公開表記に変え、関係するメディアからアプリへの導線を作った。一方で、Firebase Hostingの保存容量が上限に達し、デプロイが1日に3回止まった。

やったこと

SEADICE本体で13件、メディア側で約70件のコミットがあった。主なものは次のとおり。

分野内容
ホームページトップページを、罫線のタイルと1色のピクトグラムで組み直した。マスコット画像と光の背景をやめて文字を減らし、メディア11本をすべてタイルで表示。「AI時代の困りごと」もメディア欄に加えた
ツール退去立会いの写真記録（部屋の場所ごとに入居時と退去時の写真を並べ、国交省ガイドラインの負担表つき）、感覚過敏きろく（2タップで記録、楽になった対処の振り返り）、ペット健康クイズ（犬・猫の4択10問）を公開。感覚過敏きろくは、もとになった記事のある悩みの科学へ移した
アプリおもいだしトレーニングと科学で断つ 悪習慣ログのページを公開表記にし、App Storeボタンを付けた。独学の科学と悩みの科学にそれぞれアプリ用ページを作り、テーマの合う記事9本ずつにアプリカードを入れた
STUDY学習の進み具合・連続日数・間違えた問題を1ページで見る「わたしの学習」を追加（登録なし、記録はファイルで書き出して別の端末へ移せる）。講座のトップを地図のような作りにし、講座ごとにデザインを分けられるようにした。「ゼロから学ぶ哲学」は第1〜2章を書いた（未公開）
メディアしぐさと本音は「問い×段階」の表を作り、空いていた32マスを埋めた。AI時代の困りごとは約20本、AI時代のメンタルヘルスは「立て直す」の列を中心に追加。親が年をとったらに介護する人の気持ちメモ、独学の科学に6デザインから選べるロック画面の壁紙メーカーを公開
点検9つのメディアで記事を出典と照合し、出典のない数字や研究結果の読み違いを直した。新しい記事の見出し（h2）は、読者の問いの形で書くルールにした
障害Hostingの保存容量が上限に達し、デプロイが429エラーで3回止まった。リリースの保持数を5件にし、古い版とPRのプレビューチャネルを消して復旧

Hostingが3回止まったのはなぜ？

原因は3つ重なっていた。保持数の上限なし、設定しても古い版が残ること、PRのプレビューの3つ。

  1. リリースの保持数が無制限だった。全22サイトで毎日の自動投稿がデプロイを続け、約9,400版がたまっていた。保持数を5件に設定した
  2. 保持数を設定しても、古い版はすぐには消えない。約7.5GB分が残ったままで、デプロイが失敗し続けるため片づく機会もなかった。各サイトの最新5版以外をHosting APIで688版削除した
  3. PRのプレビューチャネルが全サイトに作られていた。しぐさと本音の下書きPR 6本が21サイトそれぞれにプレビューを作り、各10版を保持していた（約80チャネル）。すべて削除し、約11GBから5.5GBに下がった（無料枠は10GB）

学んだこと

今日は、容量の見方と、ツールやアプリを「どこに置くか」で学びがあった。

  1. 保持数の設定と、実際の削除は別もの。設定を変えても既存の版は残る。容量は Hosting API で FINALIZED の版の大きさを合計して確かめる
  2. PRごとのプレビューは、サイト数の分だけ増える。1本のPRでも21サイト分のプレビューができる。プレビューを作るサイトを絞るか、期限を短くする必要がある（未対応）
  3. ツールは、もとになった記事の隣に置く。感覚過敏きろくは本体の /tools/ に置いていたが、根拠の記事は悩みの科学にある。同じサイトに移し、記事から1つ先で使えるようにした。古いURLは301で転送している
  4. アプリに入れるURLは、メディアのアプリ用ページ1本にする。個別の記事でなくアプリ用ページを指しておけば、記事が増えてもアプリを再申請せずに中身が育つ。独学の科学では、新しい記憶の記事にも自動でアプリカードが付く設定にした
  5. 表を作ると、1日で32マス埋められる。しぐさと本音を「21の問い×5段階」の表に置くと、答えていない問いがはっきりし、そこから順に書けた
  6. 登録なしでも、記録は持ち運べる。わたしの学習はブラウザ内に保存し、JSONファイルの書き出しと読み込みで端末を移せるようにした。メールアドレスもパスワードも使わない

次にやること

  • PRのプレビューチャネルを作るサイトを絞り、Hostingの容量が再び上限に達しないようにする
  • 悩みの科学で、悪習慣をやめる記事を5本先に書き、アプリ用ページを育てる
  • ゼロから学ぶ哲学の第3章以降を書いて公開する
