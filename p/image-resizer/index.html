画像リサイザー

画像のサイズ変更・圧縮・形式変換ができる無料ツールです。画像はアップロードされず、すべてお使いの端末のブラウザ内で処理されます。

ここに画像をドロップ、またはタップして選択 JPEG / PNG / WebP / GIF・複数枚OK

使い方

  1. 画像を選択またはドロップします。
  2. 幅・高さ、出力形式、画質を指定します。
  3. App Storeに提出する場合は「App Store用サイズも同時に出力」をオンにすると、指定サイズの変換と同時にiPhone・iPad用サイズも出力されます（上の「フィット方法」で余白かカットかを選べます）。
  4. 「変換する」を押すと自動でダウンロードされます（複数枚はZIP1つにまとめて保存）。自動保存をオフにした場合は、各画像の「保存」リンクか「すべて保存」から保存できます。

よくある質問

画像は外部に送信されますか？
いいえ。変換はブラウザ内（Canvas）で行い、サーバーへは一切送信しません。

拡大もできますか？
できますが、拡大すると画質は劣化します。

PNGだと画質スライダーが効かないのはなぜ？
PNGは可逆圧縮のため画質指定がありません。軽くしたい場合はJPEGかWebPを選んでください。

写真のEXIF（位置情報など）は？
再エンコード時に削除されます。
