プライバシーポリシー（栽エンサー）

SEADICE（以下「開発者」）は、植物の成長記録を見せあうアプリ「栽エンサー」（以下「本アプリ」）における利用者情報の取り扱いについて、以下の通り定めます。

登録とIDについて

本アプリは登録なしで使えます。メールアドレス・パスワード・電話番号・SNSアカウントは使いません。初めて開いたときに、Firebase Authentication の匿名ログインで端末ごとのIDが自動で発行され、投稿やプロフィールはこのIDに結びつけて保存します。IDから氏名などの個人を特定することはできません。

保存する情報

  • 利用者が入力・投稿したもの：名前（ニックネーム）、自己紹介、育てている植物、植物の登録情報、成長記録の写真とメモ、ひとこと（コメント）、すてき（いいね）、フォロー、通報
  • 本人だけが読めるもの：ブロックした人の一覧、記録を「みんな」に載せるかの設定
  • 端末内にだけ保存するもの：利用規約に同意したかどうか、成長記録をつけた回数

位置情報・連絡先・端末の広告識別子（IDFA）は取得しません。写真は利用者が選んだもの・撮ったものだけを送信し、アップロード前に縮小します。写真に含まれる位置情報（Exif）は、縮小のときに取り除きます。

保存場所と公開範囲

投稿・写真・プロフィールは Google Cloud（Firebase: Cloud Firestore と Cloud Storage、プロジェクト: saiencer）に保存します。「みんな」に載せた記録とプロフィールは、本アプリの利用者が見られます。設定で「記録を『みんな』にも載せる」をオフにした記録は、本人だけが見られます。

利用目的

保存した情報は、本アプリの中で記録を表示し、利用者同士で見せあうためだけに使います。広告・販売・ほかのサービスでの利用はしません。トラッキング（ほかの会社のアプリやサイトをまたいで利用者を追跡すること）は行いません。

通報とフィードバック

通報は、通報した人のIDと対象・理由を saiencer のプロジェクトに保存します（同じ人が同じものを2回通報しても1件として数えます）。あわせて、開発者がすぐ気づけるよう、対象の場所（投稿・ひとこと・プロフィールのID）と理由、ひとことの場合はその先頭60字を、SEADICE のフィードバック受付（Google Cloud Firestore、プロジェクト: seadiceweb）に送ります。こちらには通報した人のIDや名前は含めません。設定画面から送った要望・不具合報告も同じ受付に保存し、アプリの改善にだけ使います。

広告・解析について

本アプリは広告を一切表示せず、第三者の解析ツールも使用しません。アプリ内課金もありません。

データの削除方法

設定の「すべてのデータを消す」で、自分の投稿・写真・植物・プロフィール・設定、自分がしたフォロー、ほかの人の投稿に送ったひとこと・すてき、そしてIDそのものを消せます。通報の記録と、約束を守らなかったために投稿を止めた記録は、場を守るために残します。個々の投稿・ひとことは、それぞれのメニューからも消せます。データを消さずにアプリを削除した場合や機種を変えた場合は、前のIDに戻れないことがあるため、下記の連絡先にご連絡いただければ、投稿の内容をもとに削除します。
