プライバシーポリシー（そのリンクちょっと待った）

SEADICE（以下「開発者」）は、iOSアプリ「そのリンクちょっと待った」（以下「本アプリ」）における利用者情報の取り扱いについて、以下の通りプライバシーポリシーを定めます。

AIで確かめるときに送る内容

本アプリは、リンクの危険度を判断するため、利用者が「確かめる」を選んだリンク、または共有メニューの「ちょっと待った」に共有したリンクについて、次の内容を開発者の判定サーバー（Cloudflare Workers）に送ります。

  • 確かめるURL（短縮URLの行き先を調べた場合は、最後の行き先のURLも）
  • 利用者が貼り付けたメッセージの文（最大1,500字）。送る前に、電話番号・メールアドレス・8けた以上の数字を端末の中で「[番号]」「[メール]」に置き換えます
  • 端末の中で行った点検の結果（注意点の見出しなど）

判定サーバーは、これらをもとに次の2つに問い合わせ、結果を本アプリに返します。

  • Google Web Risk（Google LLC）: URLだけを送り、危険サイトとして報告されているかを調べます
  • Claude（Anthropic, PBC）: URL・伏せたあとの文・点検の結果を送り、危険度と理由の文を作ります

判定サーバーは、送られた内容と結果を保存せず、ログも残しません。ただし、次の2つだけを一時的に持ちます。

  • 同じ内容を続けて確かめたときのため、内容を元に戻せない形（ハッシュ）にした鍵で、結果だけを30分間
  • 1日の利用回数の上限のため、IPアドレスを元に戻せない形にした値と、その日の回数（日付が変わると消します）

Claude への問い合わせは、SEADICEの複数のアプリで共通に使っている中継サーバーを通ることがあります。この中継サーバーは、どのアプリから呼ばれたかの回数を数えるための記録だけを残し、送った内容は記録しません。Google・Anthropic での取り扱いは、それぞれの規約に従います。Anthropic は、API で送られた内容をAIの学習に使わないとしています。

設定で「AIで確かめる」をオフにすると、何も送らずに端末の中の点検だけで判断します（共有メニューから確かめるときも同じです。この設定は、アプリと共有メニューのあいだで端末の中だけで受け渡します）。

「中身を見てくる」について

結果の画面で「中身を見てくる」を押したときだけ、判定サーバーがそのリンク先のページを利用者の代わりに読みに行きます。利用者の端末ではページを開きません。

  • 読むのはページの文字（最初の300KBまで）だけで、プログラムの実行やファイルの保存はしません。読んだページそのものは本アプリに返さず、AI（Claude）がまとめた結果（どんなサイトか・題名・パスワードやカード番号の入力欄があるか）だけを返します
  • ドメインが作られた日を、公開されている登録情報（RDAP、rdap.org 経由）で調べます。このとき送るのはドメイン名だけです
  • リンク先のサイトには、判定サーバーからアクセスがあったことが伝わります。利用者のIPアドレスや端末の情報は伝わりませんが、一人ひとりに違うリンクを送る手口では「リンクが開かれた」と相手に分かる場合があります
  • 読んだ内容と結果は保存しません（同じリンクを続けて確かめたときのため、結果だけを30分間、元に戻せない形の鍵で一時的に持ちます）

カメラと写真について

本アプリは、QRコードを読み取るためにカメラを使います。カメラの映像は端末の中で読み取りに使うだけで、保存も送信もしません。写真から読み取る場合も、選んだ画像を端末の中で読み取るだけで、画像を送信しません（読み取ったリンクは、上のとおり確かめるときに送ります）。

収集する情報

本アプリは、利用者の個人情報を収集しません。アカウント登録・ログインはありません。

  • 端末内にのみ保存するもの：確かめたリンク・QRコードの履歴、設定（色・振動・履歴を残すか・AIで確かめるか）、取り込んだ詐欺サイトのリスト
  • 開発者に送信されるもの：上の「AIで確かめるときに送る内容」と、設定画面のフィードバック・不具合報告フォームに利用者が自分で入力して送信したテキスト

氏名・メールアドレス・位置情報・端末識別子・連絡先は取得しません。

そのほかの通信

  • 詐欺サイトのリスト：1日1回まで、開発者のサーバー（seadice-filters.web.app、Google Firebase Hosting）から取得します
  • 短縮URLの行き先調べ：利用者が「行き先を調べる」を押したとき（または設定で自動にしたとき）だけ、その短縮URLのサービスに行き先を問い合わせます
  • サイトを開く：利用者が選んだときだけ、Safariなどのブラウザで開きます。開いた先での情報の取り扱いは、それぞれのサイトの規約に従います
  • いずれの通信でも、相手のサーバーには通常のWebアクセスと同じくIPアドレスなどの通信情報が届きます。開発者はこれを利用者の特定や分析に使いません

Firestoreへのフィードバック送信について

設定画面から送信されたフィードバック・不具合報告は、Google Cloud Firestore（プロジェクト: seadiceweb）の feedback コレクションに保存され、アプリ改善の目的のみに利用されます。名前やメールアドレスは送信されないため、送信内容に返信することはできません。

広告・解析について

本アプリは、広告・トラッキング・アクセス解析の仕組みを含みません。
