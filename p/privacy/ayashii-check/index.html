プライバシーポリシー

最終更新日: 2026年10月25日 / 対象アプリ: 怪しい人チェック

SEADICE（以下「開発者」）が提供するアプリ「怪しい人チェック」（以下「本アプリ」）での、情報の取り扱いについて説明します。本アプリは登録・ログインがなく、開発者のサーバーにトークや記録を保存しません。

開発者・連絡先

開発者: SEADICE
連絡先: hi@seadice.win

端末の中だけで扱う情報

  • ユーザーが選んだLINEのトーク履歴ファイル、貼り付けた文章、トーク画面・プロフィール画面のスクリーンショット
  • スクリーンショットから読み取った文字（読み取りは端末内の Google ML Kit で行い、画像も文字も送信しません）
  • 相手ごとの記録（ユーザーが付けた呼び名、確かめた日時、見つかったサインの種類と数）。トークの本文は記録に残しません
  • LINEのトーク履歴で「あなた」として選んだ名前、購読の期限、回数券・会う前チェックの残り、AIのレポートの利用回数

これらは端末内（SharedPreferences）にだけ保存され、開発者のサーバーには送られません。

AIのレポートを作るときの送信（Anthropic Claude API）

送信する内容: 確かめたトークやプロフィールの文章（新しい方から最大6,000字程度）と、見つかったサインの名前。送る前に、名前・電話番号・メールアドレス・URL・ID・住所らしい部分を端末内で伏せ字にします。画像は送りません。

送信先: 開発者が運用する Cloudflare Workers のプロキシ（claude-proxy.seadice-lite.workers.dev）を経由して、米国 Anthropic, PBC 社の Claude API に送られます。プロキシはトークを保存せず、使いすぎを防ぐための呼び出し回数とアプリ名だけを数えます。

利用目的: レポート（怪しさの読み直し・確かめる質問・会う前に確かめること・当日の安全メモ）を作るためだけに使います。

同意の取得: レポートを作るたびに、伏せ字にした送信内容の全文と送信先を表示し、ユーザーが「送って作る」を選んだ場合だけ送ります。トークには相手の発言が含まれます。

送信内容は Anthropic 社のプライバシーポリシー（https://www.anthropic.com/legal/privacy）にもとづいて処理されます。

写真の使い回しを調べるとき

「相手の写真の使い回しを調べる」を押すと、ユーザーが選んだ写真を iPhone の共有メニューに渡します。どのサービス（Google など）に送るかはユーザーが選び、本アプリは写真を保存・送信しません。

App内課金

購入と支払いは Apple が行います。開発者は支払い情報や Apple ID を受け取りません。購読の状態・回数券の残りは端末内に記録します（回数券と会う前チェックの残りは、アプリを削除すると消えます）。

要望・不具合の送信

設定画面の「アプリを一緒に育てませんか？」「不具合を報告する」から送った文章（200字まで）だけが、開発者の Firebase（Google Cloud Firestore）に保存されます。名前やトークの中身は書かないようお願いしています。

広告について

本アプリは広告を表示せず、広告事業者とデータを共有しません。

データの削除方法

相手ごとの記録は「相手」タブの削除ボタンで消せます。アプリを削除すると、端末内のすべての記録が消えます。

プライバシーポリシーの変更

本ポリシーを変えたときは、このページに掲載した時点で効力を生じます。
