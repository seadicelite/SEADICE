SEADICE（以下「開発者」）が提供するiOSアプリ「NLPで人生改善を試す30日」（以下「本アプリ」）における、ユーザーの情報の取り扱いについて説明します。

開発者・連絡先

開発者: SEADICE
連絡先: hi@seadice.win

端末の中だけに保存する情報

本アプリは、次の情報をお使いの端末の中（SharedPreferences）だけに保存します。開発者のサーバーや外部のサービスには送信しません。

  • 各日の記録（試した日付、役立ち度、試す場面、書いたメモ）
  • お気に入りにした技法
  • 毎日のお知らせのオン・オフと時刻
  • 案内を一度出したかどうかの印（同じ案内を二度出さないため）

バージョン1.1.0以降、AIの機能はなく、書いたメモを外部に送ることはありません。毎日のお知らせは端末の中で予約するだけで、どこにも送りません。氏名・連絡先・位置情報などの入力は求めません。

送信する情報

設定画面の「アプリを一緒に育てませんか？」「不具合を報告する」から文章を送った場合に限り、その文章と、どのアプリから送られたかを示す識別名（nlp-mindshift）を、Google の Firebase（Cloud Firestore）に送信します。氏名・メールアドレス・端末の識別子などは送信しません。送られた内容は、アプリの改善と不具合の調査だけに使います。文章には、ご自身や第三者を特定できる情報を書かないでください。

新しいバージョンがあるかを確かめるため、起動時に Apple の公開情報（iTunes Search API）に本アプリの識別子を問い合わせます。ユーザーに関する情報は送りません。

Google のプライバシーポリシー: https://policies.google.com/privacy

記録の書き出し・共有

「記録を書き出す」「手札を共有」「アプリを共有する」を押したときだけ、端末の共有の画面が開きます。どこに送るかはユーザーが選び、開発者には届きません。

広告・計測・課金について

本アプリには広告も、利用状況を計測する仕組みもありません。広告識別子（IDFA）も使いません。アプリ内課金もありません。

内容について

本アプリは NLP（神経言語プログラミング）の技法を試すためのアプリです。NLPは研究で効果がほとんど確かめられていない方法で、アプリの中でも各技法の研究の強さを示しています。医療的な診断・治療・心理療法の代わりではありません。つらい気持ちが強いときや長く続くときは、医療機関や相談窓口に相談してください。

データの削除

  • 設定の「記録を消してやり直す」で、端末内の記録とお気に入りを消せます
  • アプリを削除すると、端末内のすべてのデータが削除されます
  • 送ったフィードバックの削除をご希望の場合は、上記の連絡先までご連絡ください

以前のバージョンについて

バージョン1.0では、「AIコーチにフィードバックをもらう」を押したときに、書いた実践ログの文章を、開発者が運用する Cloudflare Workers のプロキシを経由して Anthropic 社の Claude API に送信します。この機能はバージョン1.1.0で取り除きました。以前に受け取ったAIのコメントは、端末の中の記録に残したままにしています。
