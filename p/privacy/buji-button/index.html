プライバシーポリシー（無事ボタン）

SEADICE（以下「開発者」）は、iOSアプリ「無事ボタン」およびアプリに含まれるウィジェット（以下あわせて「本アプリ」）における利用者情報の取り扱いについて、以下の通りプライバシーポリシーを定めます。

収集する情報

本アプリは、利用者の個人情報を収集しません。アカウント登録・ログインはありません。氏名・電話番号・メールアドレス・位置情報・連絡先は取得しません。

  • 端末内にのみ保存するもの：つながっている相手の呼び名、つながりごとの番号と鍵、相手の通知の宛先（通知用のランダムな文字列）、最後に押した時刻・最後に押された時刻
  • 開発者に送信されるもの：設定画面のフィードバック・不具合報告フォームに、利用者が自分で入力して送信したテキストのみ

ボタンを押したときの通信

ボタンを押すと、本アプリは「相手の通知の宛先・つながりの番号・押した時刻・確認用の署名」を、開発者の中継サーバー（Cloudflare Workers）に送ります。中継サーバーはこれをGoogleの通知サービス（Firebase Cloud Messaging）に渡し、iPhoneにはAppleの通知サービス（APNs）を通して届きます。

  • 中継サーバーは受け取った内容を保存せず、記録（ログ）も取りません。誰と誰がつながっているかの一覧も持ちません
  • 相手の呼び名は送りません。通知に出る名前は、受け取った端末の中で付けています
  • 使いすぎを防ぐため、中継サーバーは一定時間あたりの呼び出し回数だけを数えます（内容は記録しません）
  • 通知はGoogle・Appleのサーバーを経由するため、上記の内容は両社の通知サービスを通ります。両社での取り扱いは、それぞれのプライバシーポリシーに従います

関連する記事の確認について

本アプリは、SEADICEのメディア「親が年をとったら」（oya.seadice.win）と「防犯」（bohan.seadice.win）に関連する記事のページがあるかを確かめるため、そのページを読み込むことがあります。このときサーバーには通常のWebアクセスと同じくIPアドレスなどの通信情報が届きますが、開発者はこれを利用者の特定や分析に使いません。

カメラについて

相手のQRコードを読み取るときだけカメラを使います。映像は端末の中で読み取りに使うだけで、保存も送信もしません。

Firestoreへのフィードバック送信について

設定画面から送信されたフィードバック・不具合報告は、Google Cloud Firestore（プロジェクト: seadiceweb）の feedback コレクションに保存され、アプリ改善の目的のみに利用されます。名前やメールアドレスは送信されないため、送信内容に返信することはできません。

広告・解析について

本アプリは広告を一切表示せず、第三者の解析ツールも使用しません。アプリ内課金もありません。AI（外部のAIサービス）も使用していません。

データの削除方法

アプリ内でつながりを外すと、その相手の情報は端末から削除されます。アプリをアンインストールすると、端末内の情報はすべて削除されます。Firestoreに送信済みのフィードバック内容の削除をご希望の場合は、下記の連絡先までご連絡ください。

お問い合わせ

ポリシーの変更

本ポリシーは予告なく変更されることがあります。変更後の内容は本ページに掲載した時点から効力を生じます。
