プライバシーポリシー（トレぷ｜生写真専用トレードプロフィール帳）

SEADICE（以下「開発者」）は、生写真の交換相手を探すアプリ「トレぷ｜生写真専用トレードプロフィール帳」と、同じデータを使う Web 版「生写真プロフィール帳」（namashashin.seadice.win）（以下あわせて「本サービス」）における利用者情報の取り扱いについて、以下の通り定めます。

見る・探すだけなら登録なし

表を見る、マスに譲・求を付ける、合う人を探す、相手の連絡先を開くのは、ログインなしで使えます。このとき付けた譲・求・持っているの記録と、「表示しない」にした人の一覧は、この端末の中だけに保存し、開発者のサーバーには送りません。

プロフィールを載せるとき

自分のプロフィールを載せるときだけ、Apple または Google のアカウントでログインします（Firebase Authentication）。開発者が保存して使うのは、アカウントを見分けるための番号（uid）だけです。メールアドレス・名前は本サービスでは読み取らず、表示もしません（ログインの仕組みとして Firebase の中には記録されます）。

保存する情報

  • 利用者が入れて公開するもの：ニックネーム、アイコン（色としるし）、ひとこと、レート・交換の条件、取引の方法、連絡先（SNS とフリマのアカウントID）、短いURLの名前、交換リスト（譲・求のマス）、検索に出すかどうか、最後に更新した日時
  • 利用者が作った・足した表：グループ名・シリーズ名・メンバー名・カット名と、作った人・最後に足した人の番号と日時（表はみんなが使うため、アカウントを削除しても残ります）
  • 場を守るための記録：通報の記録（対象・理由・通報した人の番号）

電話番号・メールアドレスらしい文字は載せられないようにしています。住所・本名・顔写真は載せないでください（写真は載せられません）。位置情報・連絡先・端末の広告識別子（IDFA）は取得しません。

公開範囲

「検索に出す」にしたプロフィールと交換リストは、アプリと Web 版の利用者が読めます。「出さない」にしても、短いURLやリンクを知っている人は開けます。通報の記録は運営だけが読めます。

保存する期間（自動で消える仕組み）

使われなくなったデータを残さないため、最後の更新（マスの変更・プロフィールの保存・「まだ交換しています」）から30日たつと検索から外れ、さらに30日たつと、プロフィール・交換リスト・短いURL・ログインのアカウントをまとめて自動で消します。この仕組みはアプリの公開日から数えます。

保存場所

Google Cloud（Firebase: Cloud Firestore・Authentication、プロジェクト: namashashin-profile）に保存します。

利用目的

保存した情報は、本サービスの中でプロフィールと交換リストを表示し、交換できる相手を探し、荒らしを防ぐためだけに使います。広告・販売・ほかのサービスでの利用はしません。トラッキング（ほかの会社のアプリやサイトをまたいで利用者を追跡すること）は行いません。

連絡と取引

本サービスの中では会話・取引をしません。連絡先のボタンを押すと、相手に送るあいさつ文（「トレぷから来ました」と交換したい写真の名前）を端末のクリップボードにコピーしてから、相手の SNS やフリマのページを開きます。あいさつ文は開発者のサーバーには送りません。開いた先でのやりとりは各サービスの規約とプライバシーポリシーに従います。

通報・リクエスト・フィードバック

通報は運営が毎日確かめ、なりすまし・個人情報・高額転売やお金の要求・荒らしなど約束に反するプロフィールは消します。ログインしていないときの通報、表の追加のリクエスト（グループ名・シリーズ名）、設定画面から送った要望・不具合報告は、SEADICE のフィードバック受付（Google Cloud Firestore、プロジェクト: seadiceweb）に保存し、運営とアプリの改善にだけ使います。

広告・解析・課金について

本サービスは広告を一切表示せず、第三者の解析ツールも使用しません。アプリ内課金もありません。

データの削除方法

アプリの「プロフィール」→「アカウントを削除」で、プロフィール・交換リスト・短いURL・ログインのアカウントをすぐに消せます。端末の中の記録は、アプリを削除すると消えます。通報の記録は場を守るために残します。ログインできなくなった場合は、下記の連絡先にご連絡ください。
