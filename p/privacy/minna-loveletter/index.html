プライバシーポリシー（みんなのラブレター）

SEADICE（以下「開発者」）は、手書きの手紙を2人やグループで送りあい、ホーム画面のウィジェットに届けるアプリ「みんなのラブレター」（以下「本アプリ」）における利用者情報の取り扱いと、みんなで気持ちよく使うための約束を、以下の通り定めます。本アプリは13歳以上の方が対象です。

登録とIDについて

本アプリは登録なしで使えます。メールアドレス・パスワード・電話番号・SNSアカウントは使いません。初めて開いたときに、Firebase Authentication の匿名ログインで端末ごとのIDが自動で発行され、呼び名・グループ・手紙はこのIDに結びつけて保存します。IDから氏名などの個人を特定することはできません。

預かる情報

次の情報は、グループの相手に手紙を届けるためだけに、サーバーに預かります。

  • 呼び名（グループのメンバーに見えます）
  • グループの名前、メンバー、作った人、メンバーが入った時刻
  • 手紙：手書きの線のデータ（書いた順番と時刻を含みます。書いているところを再生するため）、ひとこと、便箋の色、宛先、送った時刻、ハートを付けた人
  • 招待：招待リンクと8文字の招待コード（7日で使えなくなり、自動で消えます）。グループから外された人の ID（外された人が同じグループにまた入れないようにするため）
  • 通知：通知を許可した場合、通知を届けるための端末の宛先（Firebase Cloud Messaging のトークン）。本人だけが読み書きできます
  • 使いすぎを防ぐための数：その日に送った手紙・作ったグループや招待・通報などの回数（3日で自動で消えます）、招待で入ろうとした回数（2時間で自動で消えます）
  • 通報：通報した人のID、対象の手紙、理由
  • 本人だけが読めるもの：ブロックした人の一覧

次の情報は、端末の中にだけ保存し、送信しません：どの手紙を開いたか（新着の印に使います）、最後に送ったグループ、見本のグループで書いた手紙、ウィジェットに出すための手紙の画像。また、アプリを閉じていてもウィジェットを書き換えられるよう、匿名IDでサーバーに入るための情報を、この端末のアプリとウィジェットの間だけで共有します。

通知について

通知を許可すると、手紙が届いたときに「〇〇から手紙」「グループ名」だけをお知らせします。手書きの絵やひとことは通知に載せません。送った人をブロックしている場合は通知しません。通知が届くと、端末の中で手紙を取りに行き、ウィジェットを書き換えます。通知は iPhone の設定でいつでも止められます。

位置情報・連絡先・写真・端末の広告識別子（IDFA）は取得しません。クリップボードは、招待コードの入力欄の「貼る」を押したときだけ読みます。

保存場所と見られる人

預かる情報は Google Cloud（Firebase: Cloud Firestore と Cloud Functions、東京リージョン、プロジェクト: minna-loveletter）に保存します。手紙を読めるのは、同じグループのメンバーのうち、その手紙の宛先になっている人（「全員」宛てならメンバー全員）と、送った本人だけです。グループから抜けた人・外された人は、それ以降の手紙を読めません。開発者は手紙の中身を読みません。通報された手紙だけを、対応のために確認します。

利用目的

預かった情報は、本アプリの中で手紙を届けて表示するためだけに使います。広告・販売・分析・ほかのサービスでの利用はしません。トラッキング（ほかの会社のアプリやサイトをまたいで利用者を追跡すること）は行いません。

通報とフィードバック

手紙は、それぞれのメニューから通報できます。同じ人が同じ手紙を2回通報しても1件として数え、3人から通報された手紙は自動で見えなくなります。通報が届くと、SEADICE のフィードバック受付（Google Cloud Firestore、プロジェクト: seadiceweb）に、通報の理由と確認用のリンクが届きます。開発者は通報を24時間以内に確認し、約束に合わない手紙は削除し、送った人の送信を止めます。

広告・解析について

本アプリは広告を一切表示せず、第三者の解析ツールも使用しません。

データの削除方法

設定の「すべてのデータを消す」で、自分が送った手紙、ほかの人の手紙に付けたハート、グループへの参加、自分が作った招待、呼び名、ブロックの一覧、通知の宛先、そしてIDそのものをサーバーから消せます。グループから抜けるだけなら、グループの画面の「このグループを抜ける」を使います。通報の記録と、約束を守らなかったために送信を止めた記録は、場を守るために残します。すでに相手の端末に届いた手紙（ウィジェットの画像を含みます）は、相手の端末に残ることがあります。データを消さずにアプリを削除した場合や機種を変えた場合は、前のIDに戻れないことがあるため、下記の連絡先にご連絡いただければ、手紙の内容をもとに削除します。

みんなの約束（利用規約）

本アプリを使うには、この約束に同意していただく必要があります。App Store での購入と利用には、Apple の標準使用許諾契約（EULA）も適用されます。

  • 悪口・いやがらせ・おどしを送らない
  • 性的な絵や言葉、暴力的な絵や言葉を送らない
  • 住所・電話番号など、自分やほかの人を特定できる情報を書かない
  • ほかの人になりすまさない。宣伝・勧誘・お金のやりとりに使わない
  • 招待リンクや招待コードを、知らない人が見る場所に貼らない
  • 法律や他人の権利（著作権など）に反することをしない

約束に合わない手紙は、通報をもとに開発者が確認して削除し、送った人の送信を止めることがあります。困ったときは、手紙のメニューから「通報する」「この人をブロックする」を使ってください。ブロックすると、その人の手紙はアプリでもウィジェットでも見えなくなり、相手には知らされません。グループを作った人は、メンバーを外したり、招待リンクを止めたりできます。

本アプリは、手紙が必ず届くこと・すぐ届くことを約束するものではありません。ウィジェットの更新は iOS の仕組みに従い、遅れることがあります。ウィジェットは iOS 17 以上で使えます。
