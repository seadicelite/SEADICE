プライバシーポリシー

HSPナビ

開発者: SEADICE  |  最終更新: 2026年10月14日

SEADICE（以下「当開発者」）は、iOSアプリ「HSPナビ」（以下「本アプリ」）におけるユーザーの個人情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。

1. 端末の中だけに保存する情報

本アプリは、次の情報を端末の中（SharedPreferences）にだけ保存します。当開発者のサーバーには保存しません。

  • ライフハックの「試した」と、接し方ガイドの「参考になった」の印
  • 選んだ表示言語
  • その日のAI相談の利用回数（1日の上限を数えるため）
  • はじめての案内を表示したか、セルフチェックやAI相談を使った回数（評価のお願いや解説記事のリンクを出す時期を決めるため）

セルフチェックの回答と結果、AI相談に入力した文章とAIの回答は、保存しません。画面を閉じると消えます。

2. 送信する情報

AI相談（使ったときだけ）

AI相談で「相談する」を押したときに限り、選んだ場面と入力した文章を、Cloudflare Workers を経由して Anthropic 社の Claude API に送り、回答を作ります。送った内容は当開発者のサーバーには保存しません。氏名・連絡先など、ご自身や第三者を特定できる情報は入力しないでください。

Anthropic 社のプライバシーポリシー: https://www.anthropic.com/legal/privacy

要望・不具合の報告（送ったときだけ）

設定画面の要望フォーム・不具合報告から文章を送った場合に限り、その文章と、どのアプリから送られたかを示す識別名（hsp-relationship-check）を、Google の Firebase（Cloud Firestore）に送ります。氏名・メールアドレス・端末の識別子などは送りません。送られた内容は、アプリの改善と不具合の調査だけに使います。

Google のプライバシーポリシー: https://policies.google.com/privacy

新しいバージョンの確認

起動時に、App Store に新しいバージョンがあるかを Apple に問い合わせます（アプリの識別名だけを送り、利用者の情報は送りません）。

3. 広告・計測について

本アプリには広告を表示する仕組みも、利用状況を計測する仕組みもありません。広告識別子（IDFA）も使いません。外部のフォントも読み込みません。

4. 外部のページを開く場合

「もっと知る」の解説記事、出典の論文、関連アプリ、このページなどのリンクを押すと、端末のブラウザで外部のページが開きます。開いた先のページでの情報の取り扱いは、それぞれのサイトの方針に従います。

5. データの削除と、以前のバージョンについて

  • アプリを削除すると、端末の中のデータはすべて消えます
  • 送った要望・不具合の報告を消したい場合は、下のお問い合わせ先までご連絡ください

以前のバージョン（1.0）は、広告の仕組み（Google AdMob）を含み、広告の配信のために端末の識別子と利用状況のデータを扱っていました。1.1.0 から広告の仕組みを外しました。

6. 診断結果について

本アプリが提供するセルフチェック結果およびAIによる分析・アドバイスは、一般的な心理学的知見を参考にした参考情報であり、医学的診断や専門的なカウンセリングに代わるものではありません。深刻な悩みがある場合は専門機関にご相談ください。

7. 子どものプライバシー

本アプリは13歳未満の子どもを対象としていません。13歳未満の方は保護者の同意のもとでご利用ください。

8. プライバシーポリシーの変更

本ポリシーは必要に応じて改定します。重要な変更がある場合はアプリ内またはこのページでお知らせします。
