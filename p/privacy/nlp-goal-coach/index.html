NLP式ゴールコーチ

開発者: SEADICE  |  最終更新: 2026年10月13日

SEADICE（以下「当開発者」）は、iOSアプリ「NLP式ゴールコーチ」（以下「本アプリ」）におけるユーザーの個人情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。

1. 端末の中だけに保存する情報

本アプリは、次の情報をお使いの端末の中だけに保存します。当開発者のサーバーや外部のサービスには送信しません。

  • 入力した目標と、ふりかえりの記録
  • 続けた日数などの記録
  • おすすめ表示などの設定

バージョン1.1.0以降、AIによる機能はなく、入力した内容を外部のAIサービスに送ることはありません。

2. 送信する情報

設定画面のフィードバック・不具合報告から文章を送った場合に限り、その文章と、どのアプリから送られたかを示す識別名を Google の Firebase（Cloud Firestore）に送信します。氏名・メールアドレス・端末の識別子などは送信しません。送られた内容は、アプリの改善と不具合の調査だけに使います。

Google のプライバシーポリシー: https://policies.google.com/privacy

起動時に、新しいバージョンがあるかを Apple の iTunes Search API で確認します。この通信で利用者を特定する情報は送信しません。

3. 広告・計測について

本アプリには広告を表示する仕組みも、利用状況を計測する仕組みもありません。広告識別子（IDFA）も使いません。

4. データの削除

  • アプリを削除すると、端末内のすべてのデータが削除されます
  • 送ったフィードバックの削除をご希望の場合は、下記のメールアドレスまでご連絡ください

5. 以前のバージョンについて

バージョン1.0系では、目標整理や書き換え提案などのAI機能を使ったときに、入力した目標や思い込みの記述を Anthropic 社の Claude API に送信していました。また、提供時期によっては広告SDK（Google AdMob）を含んでいました。これらはバージョン1.1.0で取り除いています。

6. ご利用にあたって

本アプリの内容は自己理解・学習のための参考情報であり、医学的・心理学的な診断や専門家の助言に代わるものではありません。

7. 子どものプライバシー・本ポリシーの変更

本アプリは13歳未満の方を対象としていません。13歳未満の方は保護者の同意のもとでご利用ください。本ポリシーは必要に応じて改定し、このページでお知らせします。
