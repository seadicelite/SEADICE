愛着スタイル診断

開発者: SEADICE  |  最終更新: 2026年10月13日

SEADICE（以下「当開発者」）は、iOSアプリ「愛着スタイル診断」（以下「本アプリ」）におけるユーザーの情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。

1. 端末の中だけに保存する情報

本アプリは、次の情報をお使いの端末の中だけに保存します。当開発者のサーバーや外部のサービスには送信しません。

  • 診断で選んだ相手の種類（恋人・配偶者、友人、母親、父親）
  • 診断の質問への回答と、診断結果の履歴
  • 表示言語などの設定

診断・結果の解説・相性の表示は、すべて端末の中で行います。バージョン1.1.0以降、AIによる解説・相談の機能はなく、回答や相談内容を外部に送ることはありません。

2. 送信する情報（任意のフィードバックのみ）

設定画面の「アプリを一緒に育てませんか？」「不具合を報告する」から文章を送った場合に限り、その文章と、どのアプリから送られたかを示す識別名（attachment-style）を、Google の Firebase（Cloud Firestore）に送信します。氏名・メールアドレス・端末の識別子などは送信しません。送られた内容は、アプリの改善と不具合の調査だけに使います。文章には、ご自身や第三者を特定できる情報を書かないでください。

Google のプライバシーポリシー: https://policies.google.com/privacy

3. 広告・計測について

本アプリには広告を表示する仕組みも、利用状況を計測する仕組みもありません。広告識別子（IDFA）も使いません。

4. 外部のページを開く場合

「もっと知る」の記事、研究の論文、関連アプリ、プライバシーポリシーなどのリンクを押すと、端末のブラウザで外部のページが開きます。開いた先のページでの情報の取り扱いは、それぞれのサイトの方針に従います。

5. データの削除

  • 診断履歴の画面で、記録を左にスワイプすると個別に削除できます
  • アプリを削除すると、端末内のすべてのデータが削除されます
  • 送ったフィードバックの削除をご希望の場合は、下記のメールアドレスまでご連絡ください

6. 診断結果について

本アプリの診断は、研究で使われている尺度（ECR-RS 日本語版、古村・村上・戸田, 2016）を使ったセルフチェックです。医学的診断や臨床心理士による評価に代わるものではありません。結果は自己理解のための参考としてご利用ください。つらい気持ちが強いときや長く続くときは、身近な人や専門の相談先に相談してください。

7. 以前のバージョンについて

バージョン1.0系では、AI解説・相性分析・AI相談を使ったときに、診断の点数や入力した文章を Anthropic 社の Claude API に送信していました。また、提供時期によっては広告SDK（Google AdMob）を含んでいました。これらはバージョン1.1.0で取り除いています。

8. 子どものプライバシー・本ポリシーの変更

本アプリは13歳未満の方を対象としていません。13歳未満の方は保護者の同意のもとでご利用ください。本ポリシーは必要に応じて改定し、このページでお知らせします。
