プライバシーポリシー

最終更新日: 2026年10月13日

SEADICE（以下「開発者」）は、「好奇心タイプ診断」（以下「本アプリ」）における利用者の情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。

開発者・連絡先

開発者: SEADICE
お問い合わせ: hi@seadice.win

端末の中だけに保存する情報

本アプリは、診断の回答と結果の履歴、最新の好奇心タイプ、小さな挑戦の回数などを、お使いの端末の中だけに保存します。当開発者のサーバーや外部のサービスには送信しません。バージョン1.1.0以降、AIによる機能はなく、回答を外部のAIサービスに送ることはありません。

送信する情報

設定画面のフィードバック・不具合報告から文章を送った場合に限り、その文章と、どのアプリから送られたかを示す識別名を Google の Firebase（Cloud Firestore）に送信します。氏名・メールアドレス・端末の識別子などは送信しません。送られた内容は、アプリの改善と不具合の調査だけに使います。

Google のプライバシーポリシー: https://policies.google.com/privacy

起動時に、新しいバージョンがあるかを Apple の iTunes Search API で確認します。この通信で利用者を特定する情報は送信しません。

広告・計測について

本アプリには広告を表示する仕組みも、利用状況を計測する仕組みもありません。広告識別子（IDFA）も使いません。

データの削除方法

アプリを削除すると、端末内のすべてのデータが削除されます。送ったフィードバックの削除をご希望の場合は、上記の連絡先までご連絡ください。

以前のバージョンについて

バージョン1.0系では、診断結果・アドバイスを作るために、質問への回答パターンを開発者が管理する中継サーバー（Cloudflare Workers）経由で Anthropic 社の Claude API に送信していました。これはバージョン1.1.0で取り除いています。

プライバシーポリシーの変更

本ポリシーの内容は、法令の変更その他必要に応じて、利用者に通知することなく変更することがあります。
