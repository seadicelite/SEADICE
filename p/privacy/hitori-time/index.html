プライバシーポリシー（ソロチャレンジ）

最終更新日: 2026年10月18日

「ソロチャレンジ」（以下「本アプリ」。バージョン1.xの名前は「ひとりじかんノート」）は、SEADICE（個人開発者、以下「開発者」）が提供するアプリです。本ポリシーは、本アプリにおける利用者情報の取り扱いについて説明します。

要点

  • アカウント登録・ログインはありません。名前・メールアドレスなどの個人情報は集めません
  • 記録と写真は端末の中だけに保存します。開発者のサーバーには送りません
  • AIの仲間の返事を作るときだけ、報告の文と最近の記録の要約を、同意を得たうえでAIに送ります。写真は送りません。送った内容は保存しません
  • 広告はありません

開発者・お問い合わせ

開発者: SEADICE
連絡先: hi@seadice.win

端末の中に保存する情報

次の情報は端末の中（SharedPreferences と、アプリの書類フォルダ）に保存します。開発者のサーバーには送りません。端末のバックアップ（iCloud など）には、iOSの仕組みにより含まれます。

  • 参加しているチャレンジ（名前・頻度・段階・アイコン）
  • 報告の内容（日時・段階・ひとこと・星・かかった時間）と、AIの仲間の返事・スタンプ
  • 報告に付けた写真（選んだときに縮小してアプリの書類フォルダにコピーします）
  • 記録画像・卒業証書の画像、書き出したファイル
  • AI機能の1日の利用回数、設定（選んだ仲間、通知の時刻と曜日、ロックのオン/オフ、同意の有無、表示済みの案内など）
  • バージョン1.xで保存した記録（ひとり時間ログ・提案履歴・雑談の履歴）。消さずに残し、「以前の記録」として表示します

写真ライブラリ・カメラは、利用者が報告に写真を付けるときだけ使います。Face ID / Touch ID は、利用者がアプリのロックをオンにしたときの本人確認だけに使い、生体情報はアプリにも開発者にも渡りません（iOSが端末の中で確認します）。

AI（Claude API）に送る情報

AIの仲間の返事は、開発者が管理するプロキシサーバー（Cloudflare Workers）を経由して、Anthropic社の Claude API で作ります。返事を作るときだけ、次の情報を送ります。

  • 今回の報告: チャレンジ名・状態（できた・ちょっとだけ・休み）・段階・ひとこと・星・時間帯・節目（初めて・回数など）・前回からの変化
  • そのチャレンジの最近の記録の要約: 直近5件の何日前か・時間帯・状態・段階・星・ひとこと、合計回数
  • 仲間への返信として書いた文
  • 卒業式の送る言葉を作るときは、記録のまとめ（チャレンジ名・回数・段階）

送らないもの: 写真、氏名・連絡先、端末の識別子。
送信先: Anthropic, PBC（米国）。
同意: 初めてAIの返事を使うとき、送る内容と送信先を示して同意をいただきます。同意しない場合や、仲間の画面でAIの返事をオフにした場合は何も送らず、通信なしで作る定型の返事を表示します。
保存: 送った内容は返事を作るためだけに使い、プロキシサーバーには保存しません。Anthropic社は、API経由の入力をモデルの学習に使いません。詳しくはAnthropic社のプライバシーポリシーをご確認ください。
回数: AIの返事は1日10回までです。回数は端末の中で数えます。

通知

チャレンジごとに通知をオンにしたときだけ、通知の許可をお願いします。通知は端末の中で予約するもので、外部のサーバーからは送りません。通知の本文にはチャレンジ名と仲間の名前が出るため、ロック画面にも表示されます（iOSの設定で隠せます）。

その他の通信

  • 新しいバージョンがあるかを確かめるため、Appleの公開API（itunes.apple.com）に本アプリのBundle IDを問い合わせます
  • 設定画面の「要望」「不具合の報告」から送った文は、開発者のFirebase（Google）に保存されます。名前や連絡先は送られません。返信が必要なときはメールでお問い合わせください

記録の書き出し・共有

記録画像・卒業証書・書き出したファイル（JSON・CSV、写真を含めたzip）は、利用者が共有や保存を選んだときだけ端末の外に出ます。共有先での取り扱いは、共有先のサービスの方針に従います。

広告について

本アプリは広告を表示しません。広告配信事業者は利用していません。

データの第三者提供

法令に基づく場合を除き、利用者の同意なく個人を特定できる情報を第三者に提供することはありません。

AIの仲間について

仲間（6人から3人を選べます）はAIで、人ではありません。返事は励ましと振り返りのためのもので、医療・健康・心理の診断や助言ではありません。

データの削除方法

報告はアプリ内で1件ずつ削除できます。チャレンジは「やめておく」で記録ごと消せます。すべての記録は、設定の「卒業式」の最後で消すか、アプリを削除すると消えます。

以前のバージョンについて

バージョン1.x（ひとりじかんノート）では、AIの過ごし方提案とAI雑談のために、入力した気分・したいこと・雑談の文（その回の会話履歴を含む）を、同じ方法でClaude APIに送っていました。AI機能の上限は1日3回でした。バージョン2.0.0でこれらの機能は、AIの仲間の返事と「次の一歩」のおすすめ（通信なし）に置き換わりました。

お子様のプライバシー

本アプリは13歳未満のお子様を対象としていません。13歳未満のお子様から意図的に個人情報を収集することはありません。

本ポリシーの変更

アプリの機能が変わるときは、このページを更新し、最終更新日を新しくします。
