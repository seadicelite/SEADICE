プライバシーポリシー

NLPラボ

開発者: SEADICE  |  最終更新: 2026年11月6日

SEADICE（以下「当開発者」）は、iOSアプリ「NLPラボ」（以下「本アプリ」）におけるユーザーの情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。

1. 端末の中だけに保存する情報

本アプリは、次の情報をお使いの端末の中だけに保存します。当開発者のサーバーや外部のサービスには送信しません。

  • 既読にしたレッスンと、お気に入りに入れたレッスン
  • レッスンで書いた実践メモと、その日付（カレンダーの表示に使います）
  • 表示言語などの設定

バージョン1.1.0以降、AIへの相談の機能はなく、入力した文章を外部に送ることはありません。レッスンの写真もアプリの中に入っており、表示のために外部へ通信しません。

2. 送信する情報

設定画面のフィードバック・不具合の報告から文章を送った場合に限り、その文章と、どのアプリから送られたかを示す識別名（nlp-lab）を、Google の Firebase（Cloud Firestore）に送信します。氏名・メールアドレス・端末の識別子などは送信しません。送られた内容は、アプリの改善と不具合の調査だけに使います。文章には、ご自身や第三者を特定できる情報を書かないでください。

新しいバージョンがあるかを確かめるため、起動時に Apple の公開情報（iTunes Search API）に本アプリの識別子を問い合わせます。ユーザーに関する情報は送りません。

Google のプライバシーポリシー: https://policies.google.com/privacy

3. 広告・計測について

本アプリには広告を表示する仕組みも、利用状況を計測する仕組みもありません。広告識別子（IDFA）も使いません。

4. 外部のページを開く場合

関連アプリ、ホームページ、プライバシーポリシーなどのリンクを押すと、端末のブラウザやApp Storeで外部のページが開きます。開いた先での情報の取り扱いは、それぞれの方針に従います。

5. データの削除

  • アプリを削除すると、端末内のすべてのデータが削除されます
  • 送ったフィードバックの削除をご希望の場合は、下記のメールアドレスまでご連絡ください

6. レッスンの内容について

本アプリは NLP（神経言語プログラミング）の考え方を紹介する学習アプリです。NLPの技法の多くは、研究で効果が確かめられていません。心理療法や医療に代わるものではありません。つらい気持ちが強いときや長く続くときは、身近な人や専門の相談先に相談してください。

7. 以前のバージョンについて

バージョン1.0系では、AIアドバイザーを使ったときに、入力した相談の文章を Anthropic 社の Claude API に送信していました。また、レッスンの写真を表示するときに Unsplash の画像配信サーバーへ通信していました。これらはバージョン1.1.0で取り除いています。

8. 子どものプライバシー・本ポリシーの変更

本アプリは13歳未満の方を対象としていません。13歳未満の方は保護者の同意のもとでご利用ください。本ポリシーは必要に応じて改定し、このページでお知らせします。
