About

SEADICEについて

SEADICE

AI ファーストで作る

Claude API を中核に据え、「AI があって初めて成立する」体験を設計します。ツールとしての AI ではなく、プロダクトの核として AI を組み込むのが SEADICE のスタイル。

名前の由来

SEA（海）+ DICE（サイコロ）。サイコロを振るように予測不能でワクワクするアプリを届けるという意味を込めています。

技術スタック

Flutter Dart Claude API Firebase iOS Android Web

開発方針

「自分が使いたいものを作る」をモットーに、シンプルで直感的な UI にこだわります。SEO とパフォーマンスを最優先とした設計を徹底。
