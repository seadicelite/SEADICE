About

シーダイス（SEADICE）について

SEADICE

ニッチなニーズに応える

「こんなアプリあったらいいのに」という小さな需要こそ大切にする。資格学習・習慣管理・診断ツールなど、ニッチなジャンルで本当に使えるプロダクトを届けるのが SEADICE のミッション。

AIで自動化する

ChatGPT・Gemini・Claude などの AI API を積極活用し、手作業をなくす仕組みをプロダクトに組み込む。「人間がやらなくていいことは AI に任せる」が SEADICE のスタンス。

技術スタック

Flutter Dart Claude API ChatGPT Gemini Firebase iOS Android Web

ユーザーファースト

使う人の体験を最優先に、シンプルで直感的な UI にこだわる。余計な設定や操作を限界まで減らし、開いた瞬間から使えるプロダクトを徹底して追求する。
