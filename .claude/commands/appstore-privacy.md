# App Store プライバシー設定アドバイザー

アプリの機能・使用技術を聞いて、App Store Connectのプライバシーデータ収集項目をどれにチェックすべきか教える。

## 使い方

ユーザーにアプリの以下の情報を聞く（まだ教えてもらっていない場合）:

1. **使用している認証・ログイン方法**（Google Sign-In、Apple Sign-In、メール登録など）
2. **使用しているSDK・API**（AdMob、Firebase、Analytics、外部AI APIなど）
3. **ユーザーが入力・生成するコンテンツ**（テキスト、写真、音声など）
4. **外部サービスへのデータ送信**（サーバー、サードパーティAPIなど）
5. **位置情報の使用有無**
6. **カメラ・マイクの使用有無**

## チェックリスト判定ルール

情報をもとに以下の項目をYES/NOで判定して表形式で回答する。

### 連絡先情報
- **メールアドレス** → Google/Apple/メールログインを使う場合YES
- **電話番号** → SMS認証がある場合YES
- **所在地・その他連絡先** → 通常NO

### 健康・財務・位置情報
- **健康/フィットネス** → HealthKit使用時のみYES
- **財務情報** → 決済情報を自前で扱う場合YES（StoreKit経由はNO）
- **詳細な位置情報** → GPS使用時YES
- **おおよその場所** → 大まかな位置情報使用時YES

### 機密情報・連絡先
- 通常NO

### ユーザコンテンツ
- **写真またはビデオ** → カメラ・フォトライブラリ使用時YES
- **オーディオデータ** → マイク使用時YES
- **その他のユーザコンテンツ** → ユーザが入力したテキストを外部APIに送る場合YES
- **メール/テキストメッセージ** → 通常NO

### ID
- **ユーザID** → ログイン機能がある場合YES
- **デバイスID** → AdMob等の広告SDKを使う場合YES
- **購入** → 購入履歴を収集する場合YES

### 使用状況データ
- **製品の操作** → Firebase Analytics、Mixpanel等を使う場合YES
- **広告データ** → AdMob等を使う場合YES
- **その他の使用状況** → 通常NO

### 診断
- **クラッシュデータ** → Firebase Crashlytics等を使う場合YES
- **パフォーマンスデータ** → Firebase Performance等を使う場合YES

### その他
- 通常NO

## 出力形式

表形式でチェックする項目・しない項目を整理して表示する。
さらに各項目の「トラッキングに使用するか」「サードパーティと共有するか」も合わせて案内する。

### トラッキング判定
- AdMob/広告SDKのデバイスIDは「トラッキングに使用」→ YES
- それ以外は基本NO

### サードパーティ共有判定
- 外部SDKやAPIに送るデータは「サードパーティと共有」→ YES
