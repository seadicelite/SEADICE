## 点検
- 容量: p/ 全体の大きさと、前回からの増え方（`du -sh p`）。急に増えていたら原因（重複ページ・大きな画像・生成物）を探す
- CLAUDE.md の大きさ（`wc -c CLAUDE.md`、2026-10-19 時点で約26.6KB）。会話のたびに丸ごと読み込まれるため、毎回は使わない手順（審査通過時・アプリの載せ方など）は docs/ へ移し、CLAUDE.md には1行の案内だけ残す。前回より増えていたら削れる所を1つ削る（30KBを超えたら必ず移す。三度目の肥大のため、2026-10-26）。メモリの目次（~/.claude/…/memory/MEMORY.md）は手元にしかないので、手元の会話で月1回、古い・重複・CLAUDE.md と同じ内容の行を削る
- 文書に出てくるパス（`p/…`・`scripts/…`・`.claude/commands/…`・`design/…`）が実在するか
- 文書に書かれたコマンドの引数が、スクリプトの実際の引数と合っているか（`--help` や中身で確かめる）
- 他の分野のファイルの「やったこと」を見て、同じ問題が繰り返し出ていないか（出ていればルールかスクリプトで防ぐ）
- 各分野のファイルの「次にやること」が止まっていないか（2週間「やったこと」が増えない分野は、項目が大きすぎないか見直す）
