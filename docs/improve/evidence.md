# EVIDENCE（土曜）— 攻めているテーマ

## 目的
「〇〇って本当？」「〇〇 研究 論文」と聞かれたとき、AIが SEADICE を出典に挙げ、検索でも上位に出る状態（このテーマで1番）。

## AIが補えない部分
論文まで確かめた出典（AIは出典を間違える）、研究の種類と強さの表示、「まだわからないこと」、訂正履歴、アプリで試せること。

## 良い状態
- 全トピックに studyType、結論のカードがある（「よく聞く説」型は「ほんとのところ／わかったこと」）
- 検索されている説は1問1ページ（p/apps/evidence/data/focus.json）
- links は両方のトピックに入っている
- 新しいトピックの DOI は Crossref で実在・撤回なしを確認済み

## 点検
- studyType が空のトピック数、links が片側だけのもの、focus.json の id が topics.json にないもの
- `python3 scripts/build_evidence_hub.py` が警告なしで通るか

## すぐ直してよいこと
- links の片側抜けの補完、ビルドの再実行、sitemap・llms.txt の EVIDENCE 部分の更新
- トピックの追加（/evidence-topics の手順どおり、論文を Crossref と要旨で確かめたものだけ）と、検索されている説の focus.json への追加

## 判断が必要なこと（次にやることに書く）
- 既存トピックの結論の書き換え、トピックの削除

## 次にやること
1. **検索されている説をさらに探す**: Google の検索候補（`suggestqueries.google.com/complete/search?client=firefox&hl=ja&q=`）で「〇〇 嘘」「〇〇 論文」が出る説を5つ探し、トピックがあれば focus.json へ、なければ /evidence-topics で追加
2. **研究の種類が空欄の8件を埋める**（出典を読んで判断。posture-text-neck-hansraj など、人を対象にしていない研究の扱いも決める）
3. **1問1ページの検索順位を見る**（Search Console。公開2〜4週間後＝11月上旬から。5〜20位のページは中身を足す）
