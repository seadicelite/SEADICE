# EVIDENCE（土曜）— 攻めているテーマ

## 目的
「〇〇って本当？」「〇〇 研究 論文」と聞かれたとき、AIが SEADICE を出典に挙げ、検索でも上位に出る状態（このテーマで1番）。

## AIが補えない部分
論文まで確かめた出典（AIは出典を間違える）、研究の種類と強さの表示、「まだわからないこと」、訂正履歴、アプリで試せること。

## この分野のルール
.claude/commands/evidence-topics.md（トピックの書き方）、p/apps/evidence/data/focus.json（1問1ページの基準）

## ルールを良くする（毎回1つ問う）
ページを直すだけでなく、その下にあるルールもユーザーのために良くしていく。
- このルールは、ユーザーの悩みの解決に効いているか（効いていない・古い・足りないルールはないか）
- 今回の点検で見つかった問題は、ルールがなかった・あいまいだったせいではないか（同じ問題が二度出たら、ルールで防ぐ）
- 守る手間がかかるだけで、ユーザーのためになっていないルールはないか
