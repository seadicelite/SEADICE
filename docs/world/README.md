# 世の中の観測

2026-11-12 開始。「世の中の人が何に悩み、何を欲し、世界がどう動くか」を、公的・信頼できるデータで見渡す地図。記事・ツール・アプリの「何を作るか」を、思いつきでなくここから決める。1つの問題を深く調べる台帳は [docs/problems/](../problems/README.md)（こちらで見つけた種を、そちらで掘る）。

| ファイル | 中身 | 更新 |
|---|---|---|
| [worries.md](worries.md) | 悩み（内閣府・厚労省・警察庁・文科省・国民生活センター等を、年代・立場別に） | 年1回（各調査の公表後） |
| [desires.md](desires.md) | 欲しいもの・お金と時間の使い方（家計調査・社会生活基本調査・通信利用動向調査・アプリ市場） | 年1回 |
| [trends.md](trends.md) | これから3〜5年の動き（人口・施行日が決まった制度・AIの見通し）。「決まっていること」と「見通し」を分ける | 3か月に1回 |
| [news.md](news.md) | 直近2〜3か月の最新の動き（省庁・警察・国民生活センターの新着、報道） | 週1回 |

## 使い方

- 記事を選ぶとき: 悩み（worries）× 最新（news）で問いを決め、[docs/quality/article.md（seadice-media）] の「書く前に上位を見る」で勝てるかを見る
- 施行日の前に書く: trends の年表で、施行の1〜2か月前に解説ページを置く（例: 日本版DBS 2026-12-25）
- アプリ・道具を考えるとき: desires の「お金を払う理由」と、worries の対象人数を合わせて見る。作る前に `market`・`business` 役へ

## 守ること

- 数字には出典番号。原文を開いたものは印なし、検索の抜粋・報道だけのものは「（原文未確認）」。記事やアプリに使う前に、使う数字だけ原文で確かめて印を外す
- 「見通し」は誰の予測かを書く。「SEADICEにとって」の節は推測と明記する
- 新しい年の数字が出たら直し、各ファイルの末尾に更新した日と内容を書く
