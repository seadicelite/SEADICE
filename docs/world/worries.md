# 日本の人々が今なにに悩んでいるか（公的データの見取り図）

「何を書く・何を作るか」を決めるため、悩みを**公的・信頼できる調査**で見渡す。最後の節だけはSEADICEの推測。

- 調べた日: 2026-11-12
- 調べ方: 内閣府・厚生労働省・警察庁・文部科学省・総務省・国民生活センターの公表資料を優先した。ウェブ検索で探し、取れるものは原文（HTML・PDF）を開いて数字と日付を照らした。まとめサイト・個人ブログは出典にしていない
- 印の意味: 番号 [n] は末尾の情報源。**原文を開いて確かめたものは印なし**。検索結果の抜粋や報道でしか見ていないものは **（原文未確認）**
- 内閣府の世論調査サイト（survey.gov-online.go.jp）は機械での取得を拒んだため、「国民生活に関する世論調査」の数字はすべて報道経由（原文未確認）。記事に使う前に原文で確かめる
- 見つからないものは「確認できない」と書いた。それらしい数字では埋めていない
- 調査ごとに対象・聞き方・年が違う。**表どうしの%を足したり比べたりしない**
