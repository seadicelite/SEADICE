# 日本の人々が今なにを欲しがり、何にお金と時間を使っているか

調べた日: 2026-11-12

## 調べ方

- 公的統計（総務省・厚生労働省・内閣府・消費者庁・経済産業省）を先に、足りない所だけ調査会社の公表値（矢野経済研究所・Sensor Tower）と公式発表（Apple・Google）で補った。まとめサイト・個人ブログは出典にしていない
- 数字の後ろの [n] は末尾の情報源の番号。**印なし = 原文（PDF・公式ページ）を開いて確かめた数字**。「（原文未確認）」= 原文が開けず、報道・検索結果の抜粋だけで確かめた数字
- 調査会社の数字は「調査会社」と書いた。調べ方が公的統計と違い、年をまたいだ比べ方もそれぞれの社の定義による
- 「伸びている／減っている」は、その調査が前回と比べた向き。物価が上がっているので、家計の金額は**実質**（物価の影響を除いた値）で見る
- 使った年: 家計は2025年平均（2026年2月公表）、時間の使い方は2021年（5年ごとの調査。2026年10月に次の調査があり、結果はまだ出ていない）、AIは2025年度調査（令和8年版情報通信白書、2026年7月公表）

## 3. アプリ・AIで解決したがっていること

### 3-1. 生成AIの使われ方（日本・2025年度調査）[20]

| 項目 | 数字 | 前回・比較 | 向き |
|---|---:|---|---|
| 生成AIを使ったことがある（15歳以上） | **58.8%** | 2024年度 26.7%（20歳以上） | 1年で倍以上 |
| 同（20歳以上だけ） | 52.2% | 同上 | 伸び |
| テキスト生成AIを使ったことがある | 55.0% | 24.0% | 伸び |
| 15〜19歳 | 91.7% | — | 一番高い |
| 20〜29歳 | 78.2% | — | |
| 「ほぼ毎日」使う人（利用者のうち） | 約3割（20代は約4割） | 米・独・中は4割超 | 日本が一番低い |
| 米国／ドイツ／中国の利用経験 | 75.6%／75.6%／93.6% | — | 日本より高い |

**使う理由**（利用者・日本）: 無料または安い 53.9%、時間や手間が省ける 42.8%、多様な発想や視点をくれる 34.1% [20]。米国は「人に相談しにくいことを聞ける」が比較的高い。

**使わない理由**（テキスト生成AIの非利用者・日本）: 生活や業務に必要ない 42.4%、**使い方がわからない 38.8%**（4か国で日本が一番高い）[20]。

**使い道**: 日本では「情報の理解」が一番多く、次に文書作成・校正、翻訳。15〜19歳は翻訳・学習支援の定期利用が特に高い。日常の行動や判断の相談に定期的に使う人は15〜29歳で20%超、専門家にするような相談は15〜39歳で15%超 [20]。

**AIへの感じ方**: 日本では「機械・道具」が最多、次が「辞書・百科事典」。米国・中国は「友人」、ドイツは「カウンセラー」が2番目。感情を打ち明けられる・否定されない安心感などの感覚は、日本が他の3か国より低い [20]。

## 4. 確認できなかったこと

- **「今後お金をかけたいもの」**（内閣府「国民生活に関する世論調査」の「今後の生活の力点」）: サイトが自動取得を拒否し（403）、報道にも数字がない。確認できない
- **消費者庁「消費者意識基本調査」の本体**: 同じく403。消費者白書の要約 [7] で代わりにした
- **日本のアプリのカテゴリ別・サブスク別の売上**: 公的統計はない。調査会社は日本単独の数字を有料レポートに入れていて、無料の公表値では確認できない
- **子育て費（文部科学省「子供の学習費調査」2023年度）**: PDFが開けなかった。報道では公立中3の塾など補助学習費が年39万円とあるが、原文未確認のため表に入れていない
- **メンタルヘルスのアプリ・サービスの市場規模**: 公的・調査会社の公表値が見つからない
- **時間の使い方の最新値**: 社会生活基本調査は2021年が最新。2026年調査の結果は2027年以降
- [3] 電子商取引の2025年値、[4] 日本のアプリ支出、[13] ヘルスケアの目標、[19] テレビ視聴は原文を開けていない。使うときは一次資料で確かめる

## 5. SEADICEにとって（推測）

ここから下は**推測**。上の数字から「お金を払う理由がありそうな順」に並べた。作る前に `market`・`business` で需要と競合を確かめる。

### お金を払う理由がありそうなもの（先に検討）

| 欲求（根拠） | メディア | 小さなアプリ・道具の種 | 払う理由 |
|---|---|---|---|
| **介護は費用も人も増え続ける**（12.2兆円・+2.4%、介護予防+4.4%、介護しながら働く人の割合が上昇）[12][16] | oya | 親の要介護度・使えるサービス・自己負担の早見表（道具・無料）、通院・服薬・連絡の共有記録（続ける記録→サブスク候補） | 時間と心の負担が大きく、遠くの家族と共有したい。ただし共有は端末をまたぐので、ログインの規則（Apple／Google で uid だけ）の範囲で設計する |
| **高齢者・SNS・定期購入のトラブルが増える**（高齢者32.0万件、SNS 10.1万件・5年で2倍、定期購入8.7万件）[7] | bohan・hanzai・ledger | 「この勧誘・広告は危ない？」のチェックリスト（道具）、定期購入の解約日・契約の控えを端末に残す記録 | 1件あたり平均約52.9万円の損を防げる。AIでトラブルを防ぐ使い方はまだ少なく [7]、空いている |
| **生成AIを使いたいが使い方がわからない**（非利用者の38.8%、4か国で最多）[20] | ai | 用事別の「AIへの頼み方」カードと、詐欺・偽アプリの見分け（道具） | 若い人は無料で十分なので、払うのは40代以上が中心と見る。若者からお金を取らない方針とも合う |
| **語学・資格の学び直しが伸び、AI英会話の参入が増える**（BtoC eラーニング+1.7%、語学試験が伸びる）[9][10] | dokugaku | 資格・試験の学習記録と出題（続ける記録→サブスク）。ただしAI英会話は参入が増えていて、競合が多い所は避ける | 合格という目標があり、期間内は払う理由がはっきりしている |
| **有料動画配信+13.66%、ネットで旅行・チケットを買う**[2][3] | （該当メディアなし） | — | 大手の領域。SEADICE がやることではない |

### 時間・気持ちの欲求（無料の道具とメディアで信頼を作る）

| 欲求（根拠） | メディア | 種 |
|---|---|---|
| **休みたい**（休養・くつろぎ+20分 [17]、検索の「残業キャンセル」[22]） | kokoro | 疲れの度合いを1タップで記録する道具、休み方の研究まとめ |
| **AIに相談し始めている若者**（日常の相談に定期利用する15〜29歳が20%超 [20]） | kokoro・kosodate | 「AIに相談してよいこと・人に相談すべきこと」の線引き（親向け・本人向け）。依存させる作りは使わない |
| **孤独感は約4割が持つ**（「時々ある」は減ったが横ばい圏 [21]） | kokoro・umbra | 比べない・競わない場（コミュニティ構想）の需要を測る材料。集めない・登録なしの原則とぶつかるので慎重に |
| **子どもは減るが、働きながら育てる親は増える**（出生数67.1万人、育児中の有業率85.2% [12][15]） | kosodate | 時間がない親向けの1ページで済む早見表。塾費は家計で実質-5.0% [1]、教科書・参考書も減っており、有料教材より無料の道具が合う |
| **お金の不安**（手取りは実質-1.7%、交際費-10.5%、副業希望493万人 [1][12]） | ledger | 値上げ後の家計を見直す道具（端末内で完結）、副業の詐欺の見分け（SNS相談の上位が副業 [7]） |
| **人の本音を知りたい**（直接の数字なし） | umbra | 今回の調査では裏付けがない。数字で言えるものは見つからなかった |

### 読み方のメモ

- 「伸びているのに大手がいない所」は、介護（oya）と、詐欺・トラブル防止（bohan・hanzai）の2つが一番はっきりしている。どちらも公的統計で毎年数字が更新されるので、生きたサイトの「今も正しい数字」を作りやすい
- 学び直し・語学は伸びているが小さく、競合が多い。資格を1つに絞ったニッチで考える
- 通信費・書籍・塾は家計で減っている。「節約したい」欲求の裏返しなので、有料で売るより無料の道具で信頼を作る方が合う
