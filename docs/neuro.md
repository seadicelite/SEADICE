# 脳科学マーケティング（メディア・サイト・アプリの土台、2026-11-07〜）

メディア・サイト・アプリは、脳と心の仕組み（注意・記憶・報酬・意思決定）の研究にもとづいて作る。目的は、使う人が迷わず用事を済ませ、続けられ、価値に納得してお金を払える形にすること。脳の弱点を突いて払わせることではない。「誠実」（七ヶ条）のほうが上で、ぶつかったら誠実を取る。

## 使う原則

確かさ: A＝メタ分析・大規模な再現あり（法則として長く再現されてきたものを含む）／B＝研究は複数あるが条件しだい・理論のまとめ・結論に争いがある（基準は [.claude/agents/neuro.md](../.claude/agents/neuro.md)）。

## 分野ごとの当て方

### メディア（記事）
- 結論を先に書く（h2 直下の `.answer`）。要点は、アイコン付きのカードに3〜5項目まで（1・2）
- 割合などの数字は棒グラフにする。飾りの写真・絵を足さない（2・3）
- 最後の「今日やること」は1つにして、いつ・どこで・何をするかの形で書く（7）
- FAQ や短いクイズで、読んだことを思い出させる（6）
- まだわからないことも書く（4。信頼は流暢さより強い）
- 書き方の詳細は seadice-media の `docs/quality/article.md`

### サイト・ツール（p/）
- 最初の画面に、用事の入口を1つ置く。並べる選択肢は3〜5まで（1・5）
- ボタンの位置や言葉は、見慣れた形にする。入力欄は48px以上（4・12）
- 押したら結果をすぐ返す。何がわかったかを最後に1文で書く（10）
- 初期設定は、使う人に得な方にする（9）
- 詳細は [design/README.md](../design/README.md)・[docs/tools.md](tools.md)

### アプリ
- 起動してすぐ1回使ってもらい、価値を感じてもらう（[flutter-app.md](flutter-app.md) の「最初の一歩」）
- 進み具合を見せる。記録が途切れても責めずに戻れるようにし、失う怖さで縛らない（8・11）
- 習慣のアプリは「いつ・どこで」を決めてもらう。学ぶアプリは、思い出す練習と間隔を空けた復習にする（6・7）
- 課金の案内は、価値を感じた後に1回だけ出す。何が増えるか・いつでもやめられるかを書き、おとりや偽の割引は使わない（4・11）
- 1回の使い終わりを気持ちよく終える（10）。見た目や機能を本人が選べるようにする（11）

## いつ何をするか
- **毎回**: 作る・直すときに、上の「当て方」を確かめる（点検役は呼ばない）
- **設計のとき**: 新しいアプリ（流れの「2. 設計」で必ず）、新しいツール・診断・大きなページは、`neuro` 役を呼ぶ
- **確かめ方**: 効いたかは「見る数字」（CLAUDE.md）で確かめる。そのためにデータ収集やA/Bテストはしない
