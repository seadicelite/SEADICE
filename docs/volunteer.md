# ボランティア事業 企画書（2026-10-17 案）

社会貢献活動をしている団体と個人に伴走し、課題を一緒に整理して、コンテンツ制作とWeb・アプリ開発で活動を前に進める。

> 状態: 窓口ページ [/volunteer/](../p/volunteer/index.html) を作った（2026-10-17、ユーザーの判断で1団体目より先に用意）。「最初の1団体を探しています」「実績はまだない」と正直に書いて受け付ける。

## 決まったこと

| 項目 | 内容 |
|---|---|
| 支援する相手 | NPO・ボランティア団体・地域活動団体と、個人で社会貢献活動をしている人 |
| スタンス | **伴走型**。言われた物を作るのでなく、課題を一緒に整理してから作る。作らない方がよいときは作らない |
| 支援の中身 | ①課題の整理 ②コンテンツ制作（活動紹介文・募集案内・チラシ・活動報告書・写真の整理）③Web・アプリ開発（サイト・募集ページ・小さな業務ツール） |
| 進め方 | 相談 → 整理 → 企画 → 制作・開発 → 振り返り（参加希望が増えたか等を一緒に確かめる） |
| 始め方 | 小さく試す。まず1団体 |

## SEADICEのルールとどう合わせるか

伴走型は「誠実」をいちばん行動で見せられる事業になる。ただし今のルールとぶつかる所があるので、先に決めておく。

1. **お金を取らない・あとで売らない**: 無料。支援の後に有料プランへ誘わない。広告・アフィリエイトも付けない（7ヶ条の「売らない」）
2. **作った物は相手のもの**: ドメイン・サーバー・アカウントは団体の名義で作る。SEADICEが手を離しても動き続ける形（静的HTMLなど、更新に専門知識が要らない作り）にし、引き継ぎメモを渡す。SEADICEがいないと止まる仕組みは作らない
3. **個人情報を集めない**: 相談の受付は、サイトにフォームを置かずメールだけにする。団体の情報をSEADICEのサイトに載せるのは、相手が了承した公開情報だけ。参加者名簿のような個人情報を預かる仕組みは作らない（作るなら団体のアカウントの中に作る）
4. **盛らない**: 活動紹介や募集文は団体の言葉で書き、数字や成果は団体と確かめる。AIで文章を整えても、事実を足さない。小さな団体ほどAIで書いた「立派すぎる文章」で信頼を落としやすい。これを防ぐことも支援に含める（「AI時代の問題」との接点）
5. **SNS運用の代行はしない**: 毎日の投稿は続けるのが難しく、手を離すと止まるため。サイトと検索で見つけてもらう形を手伝う

## 似た活動と、SEADICEが選ばれる理由

| 似た活動 | 形 | SEADICEの違い |
|---|---|---|
| [サービスグラント](https://www.mlit.go.jp/kankocho/positive-off/message/service_grant.html) などのプロボノ | 会社員のチームが期間とゴールを決めたプロジェクトで支援（1日〜3か月） | 1人が相談から振り返りまで通しで見る。期間が終わっても引き継げる形で渡す |
| [日本NPOセンター](https://www.interlink.or.jp/new/pdf/p29.pdf) などの中間支援 | 資金と伴走でIT活用を支える | 競合でなく、紹介してもらう先になりうる |
| Wix・Microsoftのテンプレート | 道具だけ。何を書くかは自分で決める | 「誰に何を伝えるか」の整理から手伝う |

## サイト（seadice.win）の目標とのつなぎ方

伴走そのものは検索やAIには出てこない。そこで、**伴走で何度も出てきた困りごとを、誰でも使える道具・テンプレートにして seadice.win に置く**（CLAUDE.md「AIが補えない部分」）。

- 候補（実際の支援で出てきたものから作る。先に作らない）
  - 活動紹介ページのひな形（そのまま置ける静的HTML。更新の手順つき）
  - 募集文チェック（日時・場所・持ち物・保険・連絡先などが抜けていないかを1タップで見る）
  - 活動報告書の印刷テンプレート
- 狙う検索語の例: 「ボランティア 募集文 例文」「NPO ホームページ 作り方」「活動報告書 テンプレート」（どれも答えより道具が欲しい語）
- 流れは理念と同じ: 団体の悩み → 伴走で解決 → 共通する部分を道具にする → ほかの団体も自分で解決できる

## 範囲と上限（燃え尽きないために）

伴走型は相手ごとに作業が違い、時間がかかる。今はメディア・アプリの運用もあるので、上限を先に決める（数字は案）。

- 同時に伴走するのは **1団体まで**
- 1件は **3か月まで**。その後の手入れは、引き継ぎ後の質問に答える程度
- 引き受けない物: 寄付の決済・個人情報の管理システム・SNS運用・政治や宗教の勧誘が目的の活動

## 広め方（広がりすぎない形）

**広げる部分と広げない部分を分ける**。道具とテンプレートは何人に使われても手間が増えないので、検索で広く届ける。伴走は人の手で枠に限りがあるので、紹介で少しずつ受ける。

| 段階 | 広め方 | 量の調整 |
|---|---|---|
| 1団体目 | 公開しない。身近な団体か、地域のボランティアセンター・市民活動センター1か所に直接相談する | 1件だけ |
| 2〜3団体目 | 1団体目の紹介と、相談したセンターからの紹介。団体が了承すれば事例ページを1本書く | 紹介だけで受ける |
| 道具ができたら | 道具・テンプレートを seadice.win に置き、検索で届ける。道具のページの下に「伴走支援もしています（今は受付中／停止中）」を1行だけ添える | 道具は無制限、伴走は枠つき |

- **受付の表示で量を決める**: 窓口ページに「受付中／停止中」と、受ける条件（同時1団体・3か月・無料）を書く。枠が埋まったら停止中にして、道具へ案内する。順番待ちの名簿は持たない（個人情報をためないため）
- **作った物に小さく名前を残す**: 団体のサイトのフッターに「制作支援: SEADICE」を入れるかは団体に任せる。見た団体から自然に紹介が来る程度の量になる
- **やらない広め方**: SNS・広告・支援の依頼が大量に来るプラットフォームへの掲載。枠を超えて断る数が増えると、かえって誠実でなくなる

## 最初の1団体で確かめること

1. 一番困っていたのは何だったか（サイトか、文章か、情報の整理か）
2. 作った物は、団体が自分で更新できたか
3. 参加希望・問い合わせは増えたか（団体に聞く。SEADICEは計測しない）
4. かかった時間（上限の数字が妥当か）
5. ほかの団体にも使えそうな部分はどこか（道具・テンプレートにする候補）
