# 003 フィッシング（偽サイト・偽SMS/メールによる詐取と、ネットバンキング不正送金・カード不正利用・証券口座の乗っ取り）

- カテゴリー: Security
- 調べた日: 2026-11-03
- 調べ方: 警察庁「令和7年におけるサイバー空間をめぐる脅威の情勢等について」（令和8年3月）と「令和8年上半期における〜」（令和8年9月）の本文PDFと統計データ（xlsx）を落として、図表の数字を表から直接読んだ。フィッシング対策協議会の月次報告は最新の2026年9月分を開いた。日本クレジット協会「クレジットカード不正利用被害の発生状況」（2026年9月7日公表のPDF）で年別・半期の被害額を照合した。金融庁「インターネット取引サービスへの不正アクセス・不正取引」の月別PDF（2026年10月9日更新）で証券口座の数字を確かめた。対象者の規模は総務省「令和7年通信利用動向調査」、相談件数は国民生活センター「2025年度 全国の消費生活相談の状況」、脅威の位置づけは IPA「情報セキュリティ10大脅威 2026」で見た。既存サービスは各社・各機関の公式ページで確かめた。怪しいURLは開いていない

## 問題

実在する会社（通販・カード会社・銀行・証券会社・官公庁など）を装ったメールや SMS のリンクから偽のウェブサイトに誘い、ID・パスワードやクレジットカード番号を入力させて盗む手口。盗まれた情報は、インターネットバンキングの不正送金やクレジットカードの不正利用に使われる [1]。

- 2025年のインターネットバンキング不正送金は、フィッシングが手口の約9割を占める [1]
- 二段階認証を突破する「リアルタイム型フィッシング」が令和元年頃から横行している [1]
- 2024年秋からは、銀行を名乗って企業に電話し、メールアドレスを聞き出してフィッシングメールを送る「ボイスフィッシング」で法人口座の被害が急増した。2026年5月には、電話から遠隔操作ソフトを入れさせ、企業の端末から送金させる新しい手口も急増した [1][2]
- 2025年3〜5月には、証券会社をかたるフィッシングで証券口座への不正アクセス・不正取引が急増した [1][5]
- 警察庁は、AI技術の発達で文章が自然になり、見抜きにくいフィッシングが増えていると書いている [2]

## 対象者

- インターネットを使う人ほぼ全員が受け取る側になりうる。2025年の個人のインターネット利用者の割合は 85.7%、世帯のスマートフォン保有割合は 91.8%（令和7年通信利用動向調査、調査時点は2025年8月末） [6]
- インターネット利用者のうち「金融取引」に使う人は約3割（令和6年・令和7年とも29%台） [6]
- 2025年に個人のインターネットバンキング不正送金の被害に遭った人は 4,558人。年代別では20代が最多の 1,046人、次いで50代 825人、60代 755人、40代 675人、30代 608人、70代 335人、10代 217人、80代 78人（その他3・不明16） [1]
- 法人も対象。2025年の法人の被害は 189件だが、被害額は約47.1億円で、全体の半分近い [1]
- 消費生活センターへのフィッシングの相談では、契約当事者の平均年齢は 55.3歳（2025年度） [7]

## 発生頻度・規模

- フィッシング報告件数（フィッシング対策協議会への報告）: 2019年 55,787件 → 2025年 2,454,297件。7年連続で増えた [1]
- ただし2026年上半期は約73万件（73.1万件）で、前年同期の119.6万件より少ない [2]
- 最新の月: 2026年9月は 94,661件（前月比 +12,323件）、フィッシングサイトのURL件数 49,032件、悪用されたブランド 105件 [3]
- なりすまされた業種（2026年9月の報告件数に占める割合）: EC系 約47.9%、クレジット・信販系 約35.0%、官公庁系 約5.2%、航空系 約4.6%。ブランド別では Amazon 約33.2%、Apple 約11.1%。上位5ブランドで約65.3% [3]
- 不正送金への誘導の手口（2025年、フィッシングサイトへ誘導された 4,308件）: 電子メール 2,211件、SMS 1,695件、不明・調査中 402件。SMS は2024年の 553件から約3倍に増えた [1][2]
- 警察庁が集約した海外の偽サイト等の URL 情報: 2020年 19,010件 → 2025年 1,033,675件 [1]
- 証券口座（2025年）: 不正アクセス 17,668件、不正取引 9,824件、証券会社をかたるフィッシングメール報告 316,414件 [1]
- 消費生活センターへのフィッシングの相談: 2025年度 9,016件（2024年度 11,820件） [7]

## 被害規模

- インターネットバンキング不正送金（2025年）: 4,747件、約103億9,700万円（10,397,040,069円）で過去最多。個人 約56.9億円・法人 約47.1億円 [1]
- 同（2026年上半期）: 253件、約20億7,000万円（前年同期比51%減） [2]
- クレジットカード不正利用（2025年、主要事業者40社の集計、海外発行カードは含まない）: 510.5億円。うち番号盗用 475.4億円（93.1%）、偽造 7.2億円、その他 27.9億円。2024年は 555.0億円で過去最多 [4]
- 同（2026年1〜6月、主要事業者48社）: 221.3億円。うち番号盗用 206.1億円（93.1%） [4]。警察庁は前年同期比30%減と書いている [2]
- 証券口座の不正売買金額（2025年）: 約7,408億円 [1]。金融庁の月別集計（2025年1月〜2026年9月の累計）では、売却金額 約4,372億円・買付金額 約3,837億円。金融庁は「被害口座内の不正取引の合計で、顧客の実際の損失額とは一致しない」と注記している [5]
- 2025年の不正送金のうち、約22.8億円は暗号資産交換業者名義の口座に送られた [1]
- 被害者1人あたりの金額・時間の損失（手続きや口座の止め直しにかかる手間）は、公的な数字を確認できない

## 既存サービス

**公的な窓口**
- 警察: 被害は最寄りの警察署か、警察庁の「サイバー事案に関する通報等のオンライン受付窓口」へ。技術的な相談は IPA の情報セキュリティ安心相談窓口、契約のトラブルは消費者ホットライン188 [9]
- フィッシングサイトの URL は「フィッシング110番（インターネット・ホットラインセンター）」へ通報。補償の相談は、被害に遭ったサービスの会社（不正送金は金融機関）へ [10]
- 警察庁は、都道府県警察や JC3 が把握した海外の偽サイトの URL を集約してウイルス対策ソフト事業者等に提供し、警告表示で閲覧を防いでいる [1]
- JC3（日本サイバー犯罪対策センター）は、偽ショッピングサイトの情報を ScamAdviser（日本語版「SAGICHECK」、無料の URL 確認サイト）に提供している（2023年3月〜） [11]

**業界団体の報告窓口**
- フィッシング対策協議会: メール（info@antiphishing.jp）と報告方法のページで、フィッシングメール・SMS の報告を受け付け、月次で報告状況を公表している [3]

**通信会社の迷惑SMSフィルター**
- NTTドコモ「危険SMS拒否設定」: フィッシングSMSと判定したSMSを拒否する。契約時に自動で適用（2022年3月24日から）。すべてのフィッシングSMSを拒否できるわけではないと明記 [12]
- ソフトバンク: 迷惑SMSフィルター・なりすましSMSの拒否・URLリンク付きSMSの拒否を2022年春から無料で提供 [13]
- au（KDDI）・楽天モバイルの機能は公式ページを確認できなかった（「確認できないこと」に記載）

**ブラウザ・セキュリティソフト・偽サイト判定**
- Google セーフ ブラウジング: 危険なサイトにアクセスすると警告する。毎日50億台を超える端末を保護しているとする [14]
- Safari の「詐欺Webサイトの警告」: フィッシングの疑いがあるサイトで警告する。判定に Google セーフ ブラウジングを使うことがある [15]
- トレンドマイクロ「Site Safety Center」: URL を入れると Safe／Dangerous／Suspicious／Untested で判定する無料サービス [16]

**カード・金融側の対策**
- クレジット取引セキュリティ対策協議会（事務局 日本クレジット協会）のガイドラインで、原則すべての EC 加盟店に 2025年3月末までの EMV 3-Dセキュア導入を求め、6.0版（2025年3月）で指針対策に入れた [17]
- フィッシング対策協議会は事業者に、SMS は「0005」で始まる共通番号を使う・正規メッセージに URL を書かない・DMARC を p=reject に移すことを勧めている [3]

## 不満・不足

**調査で確かめたこと**
- 通信会社のフィルターは全部は止められない（ドコモ自身が明記） [12]
- 二段階認証もリアルタイム型フィッシングで突破されている。遠隔操作で企業の普段の端末から送金させ、金融機関の端末認証や不正取引監視を避ける手口も出ている [1][2]
- AI で文章が自然になり、見抜きにくいフィッシングが増えている。警察庁は技術的な対策だけでは十分でなく、「リンクを安易にクリックしない」「公式サイトや公式アプリからアクセスする」意識が要るとしている [2]
- 2026年9月の報告で、なりすましメールの約37.8%のうち約13.8%は DMARC 未対応のドメインからで、送る側の対策が行き渡っていない [3]
- 被害者は高齢者だけではない。個人の不正送金の被害者は20代が最多 [1]
- 証券口座の金額は「顧客の実際の損失額とは一致しない」とされ、実際にいくら戻ったかは公表の数字からはわからない [5]

**推測**
- 報告は年245万件あるのに、消費生活センターへの相談は年9,016件で、困ったときに「押してしまった後に何をすればよいか」を一か所で調べられる場所が少ない可能性がある（推測。相談の少なさの理由は確かめていない）
- 既存の判定サービスは「このURLは危険か」に答えるが、「このSMSの会社は本当はどこから連絡してくるのか」「押してしまった・入力してしまった後に、カード・銀行・証券・Apple ID ごとに何をするか」を、出典つきでまとめたものは見当たらない（推測。網羅的には確かめていない）
- 判定サービスや迷惑SMSフィルターは無料で、大手が提供しているため、個人がお金を払ってまで別の判定道具を使う理由は弱い（推測）

## AI・Webで解ける所（推測）

- **手口の一次データ化**: フィッシング対策協議会の月次報告・警察庁の統計を毎月集め、なりすまされたブランド・業種・SMS の文面の型の推移を、SEADICE の表としてためて公開する（公的な数字の集約なので、利用者からデータを集めずに作れる）
- **「本物の連絡のしかた」一覧**: 主なブランド（Amazon・Apple・カード会社・銀行・証券・電力・水道・国税庁・宅配）が公式に「SMS／メールで何をする・何をしない」と書いているかを、公式ページを出典に1社ずつ確かめて並べる。AI のチャットは出典を間違えやすいので、確かめた跡が強みになる
- **押してしまった後のチェックリスト**: カード・銀行・証券・Apple ID・携帯キャリアごとに「止める・変える・届ける」を順に出す。端末内だけで完結できる
- **AI の答え合わせ**: 「このSMSは本物？」と AI に聞いたときの答えを決めた質問で定点観測し、間違いをページで示す（CLAUDE.md の「最初は AI詐欺」の型）
- **端末内の文面チェック**: 貼った文面を端末内のルール（URL の形・急がせる言い回し・共通番号でない送信元など）で見る。文面をサーバーに送らない形にすれば「集めない」と両立する。ただし判定の精度を保証できないので、「本物かどうか」は言い切らず、公式の確認先へ案内する形になる

## 事業機会（推測）

- **入口は BOHAN（情報提供）**: bohan.seadice.win に「フィッシング」の問い（届いた・押した・入力した・お金が動いた）× 対象（カード・銀行・証券・通販・Apple ID・携帯）の表を作り、各マスに「結論＋公式の出典＋やることリスト」を置く。検索語は「〇〇 SMS 本物」「フィッシング 入力してしまった」「カード番号 入力してしまった 対処」など、答えより手順が欲しい語。上の「本物の連絡のしかた」一覧と月次の一次データは、AI がまとめただけのサイトには真似しにくい
- **AIBOU（サービス提供）**: 手口を共有する掲示板アプリ AIBOU の中で、フィッシング SMS・メールの文面の型（個人情報を伏せたもの）を共有し、BOHAN の対処ページへつなぐ。投稿だけ保存の例外ルールの範囲で作れる
- **お金を払う理由が弱い所**: URL判定・迷惑SMSの遮断は、通信会社・ブラウザ・セキュリティソフトが無料で行っている。同じ土俵の判定アプリは、精度でも価格でも勝ちにくい。さらに Google Safe Browsing API は非商用に限られ、商用は有料の Web Risk API になる [18]（サーバー代を抑える方針と合わない）。過去に Safari 拡張の防犯フィルターが 4.3 で却下されている
- **払う理由が生まれうる所**: 「家族のスマホを守る」（親や子のスマホの設定点検・押してしまったときの家族向け手順）は、既存の無料判定とは別の用事。ただし需要（App Store の同種アプリの評価数）と払う意思は未確認
- **数字の流れに注意**: 2025年まで右肩上がりだったが、2026年上半期は報告件数・不正送金・カード不正利用がどれも減った [2][4]。手口は電話・遠隔操作・証券口座へと移っており、テーマは残るが、狙う手口は毎年見直す必要がある
