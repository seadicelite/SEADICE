# 001 特殊詐欺（オレオレ詐欺・還付金詐欺・ニセ警察詐欺など）

- カテゴリー: Security
- 調べた日: 2026-11-03
- 調べ方: 警察庁「令和７年における特殊詐欺及びＳＮＳ型投資・ロマンス詐欺の認知・検挙状況等について（確定値）」（2026-06-05公表）の資料1・資料2のPDFを取得してテキストを抜き出し、表と本文の数字を照らし合わせた。令和8年分は警察庁の上半期（暫定値、2026-07-30付）と8月末（暫定値、2026-10-02公表）を確認（9月末分は調べた時点で見つからなかった）。対象者の規模は総務省統計局「統計トピックスNo.149」（2026-09-20）。既存サービスは警察庁「警察庁推奨アプリ」ページ、政府広報オンライン（#9110・188）、NTT西日本の特殊詐欺対策ページ、世田谷区の自動通話録音機の貸出ページを公式ページとして確認。被害者の意識は長野県警の被害者アンケート（2026-05-21）の原文PDFを確認。検索は WebSearch、原文は WebFetch と pdftotext で読んだ。

> **集計の範囲に注意**: 令和7年（2025年）までは「特殊詐欺」と「ＳＮＳ型投資・ロマンス詐欺」は別の集計。令和8年（2026年）から警察庁は、ＳＮＳ型投資・ロマンス詐欺を特殊詐欺の一手口とし、ニセ警察詐欺を独立した手口として全体を「特殊詐欺」と呼ぶように変えた [3]。このため令和8年の数字は令和7年以前の「特殊詐欺」とそのままは比べられない。本ファイルの代表値は、令和7年の旧定義の確定値を使う。

## 問題

電話・メール・SNSなどで、対面せずに相手を信じ込ませ、振込みなどで現金等をだまし取る犯罪（恐喝・キャッシュカード詐欺盗を含む）[1]。令和7年は認知件数27,832件、被害額1,423.1億円で、どちらも過去最悪 [1][2]。

増えた主な原因は、警察官等をかたり「捜査（優先調査）」名目で現金等をだまし取る「ニセ警察詐欺」[1]。令和6年後半頃から増え、令和7年の認知件数11,014件（特殊詐欺全体の39.6％）、被害額1,005.0億円 [1]。裸になることや常時ビデオ通話を求めるなど、性的な被害を伴う手口の報告が247件（令和7年中の発生、令和8年4月末時点、未遂・相談を含む）[1]、金地金をだまし取る手口も確認されている [1]。

犯人と接触する手段は電話が約8割（78.8％）[1]。犯行に使われた電話番号は国際番号が急増し、令和7年は92,996件で全体（123,138件）の75.5％ [1][2]。警察庁は「犯人側と接触してしまえば、誰もがだまされるおそれがある」として、詐欺電話を機械的に遮断する方針を取っている [1]。

## 対象者

- **高齢者が中心だが、若い世代にも広がった**: 令和7年の高齢者（65歳以上）被害は14,273件で、法人被害を除く認知件数の51.3％（前年から-14.0ポイント）、被害額の59.2％ [1]
- **ニセ警察詐欺は件数で若い世代、金額で60〜70代**: 認知件数は30代2,239件が最多、次いで20代1,718件。被害額は70代274.6億円が最多、次いで60代256.3億円 [1]
- オレオレ詐欺の年代別認知件数（法人被害を除く）は80代以上3,235件、70代2,453件、30代2,284件、20代1,759件の順 [1]
- ニセ警察詐欺の当初接触ツールは、40代以下は携帯電話が9割以上、50代以上は固定電話が約6割 [2]
- 被害者の男女別の割合（高齢被害者、法人被害を除く）は、特殊詐欺全体で男18.5％・女32.8％（計51.3％）[1]
- 人数の目安: 65歳以上人口は3624万人（2026年9月15日現在推計、総人口の29.6％）[4]。ただし被害は20〜30代にも広がっており、「対象者」は実質的に電話を持つ全年代
- 予兆電話（住所・資産などを探る、特殊詐欺が疑われる電話で警察が把握したもの）は令和7年に331,653件 [1]。被害に至らない「接触された人」はこれより多いはずだが、実数は確認できない

- 令和7年の認知件数 27,832件（前年比+6,789件、+32.3％）[1]。これまでの最多は平成16年の25,667件 [2]
- 推移（認知件数）: 平成28年14,154件 → 令和2年13,550件（底）→ 令和5年19,038件 → 令和6年21,043件 → 令和7年27,832件 [1]
- 手口別（令和7年）: オレオレ詐欺14,489件（うちニセ警察詐欺10,859件、74.9％）、架空料金請求詐欺5,706件、還付金詐欺3,179件、預貯金詐欺1,707件、キャッシュカード詐欺盗1,243件 [1]
- 予兆電話 331,653件（前年比+71.4％、1か月平均27,638件）[1]
- 令和8年（新定義、SNS型投資・ロマンス詐欺を含む）: 1〜8月の暫定値で認知件数29,687件、被害額2,360.7億円（前年同期比+14.4％・+33.2％）。うちニセ警察詐欺は6,346件（-4.1％）・728.6億円（+27.0％）で、件数は減り金額は増えた [5]

- 既遂1件当たり 523.6万円。ニセ警察詐欺は922.5万円、ニセ警察詐欺を除くと256.7万円 [1]
- 令和8年上半期（新定義・暫定値）の既遂1件当たりは840.0万円、ニセ警察詐欺は1,163.9万円 [3]

- 参考（別集計）: 令和7年のＳＮＳ型投資・ロマンス詐欺は15,168件・1,834.3億円。特殊詐欺と合わせると43,000件・3,257.4億円 [2]

## 既存サービス

**公的窓口**
- 警察相談専用電話 **#9110**: 全国共通、管轄の警察本部の相談窓口につながる。平日8時30分〜17時15分（都道府県で異なる場合あり）、休日・時間外は一部を除き当直か音声案内。ダイヤル回線や一部のIP電話からは使えない [6]
- 消費者ホットライン **188**: 郵便番号を入れると地域の消費生活センターなどにつながる全国共通番号 [7]
- 匿名通報ダイヤル 0120-924-839（警察庁の公表資料に掲載）[8]

**電話そのものを止める（固定電話）**
- 国際電話不取扱受付センター（0120-210-364、KDDI・ソフトバンク・NTT東日本・NTT西日本・NTTドコモビジネスの5社が提供）: 10桁の固定電話の国際電話の発着信を無料で休止できる（携帯電話・050のIP電話は対象外、着信だけを止めることはできない、申込みは契約者のみ）。Web・電話・郵送で申込み、Web・電話なら1週間程度で反映 [13]。警察も「＃みんとめ」として呼び掛け [1]
- NTT西日本: ナンバー・ディスプレイ／ナンバー・リクエストを70歳以上の契約者（または70歳以上と同居の契約者）は申し出により月額・工事費無償。通話を録音・解析して疑いがあれば家族に知らせる「特殊詐欺対策サービス」もあるが、福祉割引適用者の無償化措置は申込受付終了 [9]
- 自治体の自動通話録音機の無料貸出: 例として世田谷区は東京都と連携し平成28年11月から、おおむね65歳以上の方が住む世帯に無料で貸出 [10]

**電話そのものを止める（携帯電話）**
- 警察庁推奨アプリ（令和8年3月に第1弾として2本を認定、無料）[3][8][11]
  - 詐欺対策 by NTTタウンページ: 要注意番号リストによる着信・発信の警告・遮断、国際番号・非通知の遮断（Androidのみ）、約500万件の事業者データベースで相手先名を表示 [11]
  - 詐欺バスター Lite（トレンドマイクロ）: 不審な電話の検知、発着信時の警告・自動ブロック [11]
  - 共通: 犯行に使われた番号（国際番号を含む）の発着信ブロック・警告（Android・iPhone）、国際電話番号の一括ブロック（Androidのみ）、警察庁の防犯情報の通知 [11]
- 民間アプリ: 着信識別アプリ（Whoscall など）がある。今回は公式ページで機能と利用者数を確かめていない（「確認できないこと」に記載）

**人による水際対策**
- コンビニ・金融機関の声掛け、警察と金融機関の不審取引の情報連携（令和7年末で47警察本部と847金融機関）[1]
- 犯行に使われた固定電話番号・050番号の利用停止（令和7年: 固定539件、050IP電話1,320件）、LINEアカウントの情報提供18,214件 [1]

## 不満・不足

**調査で確かめたこと**
- **iPhoneでは国際電話をまとめて止められない**: 警察庁推奨アプリ2本とも、国際電話番号の一括ブロックはAndroidのみ [11]。ニセ警察詐欺の40代以下は9割以上が携帯電話から接触されている [2]
- **声掛けで止められる割合が下がった**: 阻止率は39.8％で前年から-9.5ポイント [1]。令和8年上半期は30.9％ [3]。振込型のうちインターネットバンキング利用が40.6％（令和7年）[1] で、窓口・ATMで人が気づく場面が減っている可能性がある（ここは推測）
- **被害者の多くが「自分はだまされない」と思っていた**: 長野県警の被害者アンケート（令和7年中の県内被害者276人のうち協力した226人、ＳＮＳ型投資・ロマンス詐欺を含まない）で、「自分はだまされないと考えていた」90.3％（204人）。理由は「見破る自信があった」118人、「自分には関係ないと思っていた」80人 [12]
- **誰にも相談せずに被害に遭う**: 同アンケートで「誰にも相談できなかった」が約9割。理由は「犯人を信じていた」約7割、「犯人から誰にも相談するなと指示された」約1割 [12]
- **手口の名前を知っていても防げない**: 同アンケートでオレオレ詐欺は回答者の100％が知っていたが被害に遭っている。還付金詐欺の認知度は39.8％、キャッシュカード詐欺盗は19.9％ [12]
- **窓口の時間と回線の制約**: #9110は平日日中が基本で、休日・時間外は一部を除き当直か音声案内、ダイヤル回線や一部IP電話からは使えない [6]
- **電話を止める対策が固定電話の契約と自治体ごとに分かれている**: 国際電話の休止は契約者本人の申込み制で、Web・電話でも反映まで1週間程度、携帯電話と050のIP電話は対象外 [13]。録音機の貸出は自治体の事業で、対象も自治体が決める（例: 世田谷区はおおむね65歳以上の方が住む世帯）[10]

**推測（裏付けのある調査は見つかっていない）**
- 「電話の最中・切った直後に、これは詐欺かを確かめる手段」が弱い。犯人は「相談するな」と言い、#9110は時間帯に制約があり、遮断アプリはかかってきた番号が既知でないと止められない
- 離れて住む家族（30〜50代）が、親の電話対策（国際電話休止・推奨アプリ・録音機）を一度に済ませる手順がまとまっていない。手続きが固定電話・携帯・自治体でバラバラなため
- 20〜30代はニセ警察詐欺の「警察」という権威に弱い場面があり、高齢者向けの啓発（「息子をかたる電話」）が届いていない可能性

## AI・Webで解ける所（推測）

- **「これは本物の警察か」を1分で確かめる道具**: 警察庁・県警が公表している「警察はこう言わない」（電話で逮捕状・資産の提出・SNSでの連絡・ビデオ通話を求めない等）を、言われた言葉を選ぶだけで照らし合わせる。端末内で完結でき、個人情報は要らない
- **家族の電話対策を1枚で済ませる手順**: 固定電話（国際電話休止・ナンバー・ディスプレイ無償化・録音機の貸出）と携帯（推奨アプリ、iPhoneとAndroidの違い）を、親の環境を選ぶだけで「やることリスト」にする。帰省時に一緒に済ませる用途
- **公的統計の一次データ化**: 警察庁の月次（暫定値）・年次（確定値）を、手口×年代×接触ツール×渡し方で毎月ためて、定義変更（令和8年）の注記つきで公開する。AIが引用しやすい形（表・日付・出典）にする
- **AIの答え合わせ**: 「ニセ警察詐欺の見分け方」などをAIに聞いたときの答えを、公的資料と照らして誤りや古い情報を記録する（CLAUDE.md の「1テーマで型を作る: AI詐欺」と同じ流れ）
- AIで電話の音声をその場で判定するのは、録音・音声の送信が要るため SEADICE の約束（集めない・サーバー代を抑える）と両立しにくい。端末内で動く小さなモデルなら可能性はあるが、未確認

## 事業機会（推測）

- **既存の資産**: 防犯メディア BOHAN（bohan.seadice.win、売らない・犯罪心理の切り口）、犯罪と心理メディア hanzai、手口を共有する掲示板アプリ AIBOU（企画中）、怪しい人チェック（企画中）。BOHAN で「知る」、上の確認ツールで「その場で解く」、AIBOU・怪しい人チェックで「続けて使う」の流れが作れる
- **勝ち筋**: 遮断（番号データベース）は NTT・トレンドマイクロ・警察庁の連携が無料で押さえており、個人では勝てない。SEADICE が取れるのは「電話に出てしまった後・切った後」の確認と、「家族の対策をまとめて済ませる」手順、そして公的統計を定義変更まで追った一次データ。どれも登録・個人情報なしで作れる
- **お金を払う理由**: 弱い。公的窓口と推奨アプリが無料のため、詐欺の確認そのものに課金するのは難しい。払う可能性があるのは、(1) 離れて住む家族が親の対策を続けて管理する機能（記録は端末内）、(2) 怪しい人チェックのような、詐欺以外の業者・既婚者なども含めた「人を見る」機能。どちらも需要は未確認
- **リスク**: 「警察」をかたる詐欺の題材なので、SEADICE 自身が公的機関と誤認される見た目・文言を避ける必要がある。被害に遭った人の相談は #9110・188 に案内し、法律・捜査の判断はしない
- **注意（ユーザーの見立て）**: サイトのツールは基本使われない、という見立てがある（MEMORY）。道具はアプリ（AIBOU・怪しい人チェック）に入れる前提で、Web は検索とAIの紹介の入口に使うほうが合う可能性がある
