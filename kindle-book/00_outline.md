# 仮タイトル案

- AIと作った100本のアプリ ― 個人開発者SEADICEの記録
- 毎日1本、AIとアプリを出し続けた ― 失敗と方針転換の全記録
- CLAUDE.mdに書いた失敗 ― AI開発の現場ノート

（本の性格: 読者向けノウハウ本ではなく、自分用の記録。時系列＋失敗談中心）

# 章立て案

1. **はじめに: なぜ毎日1本だったのか**（第1章・試し書き済み）
2. **CLAUDE.mdという「育てる指示書」**: ルールが増えていった経緯
3. **量産から「困りごと解決」へ**: 企画方針の転換（Before→After型ニッチ）
4. **Apple審査で落ちた話**: share_plus / iPadOS 26、Deployment Target警告
5. **広告が死んだ日**: AdMob停止と、広告なし・買い切り・支援ページへの転換
6. **APIキーとコストの防波堤**: Claude APIプロキシと日次利用上限
7. **AIに任せたこと、任せられなかったこと**: 自己採点と実機確認のズレ
8. **これから**: SEADICE HUB、多言語、団体としての目標

# 執筆メモ

- 各章に「その時の判断」「起きた失敗」「今のルール」の3点を入れる
- 数字（本数、日付、売上）は実データで埋める。分からない箇所は【要確認】で残す
- 漫画化するなら第4・5章の山場を4コマにするのが費用対効果が高い
