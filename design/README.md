# サイト設計（seadice.win）

テーマは**質実剛健**。飾り（グラデーション・ぼかし・光・影）は使わず、文字の大きさ・余白・罫線で整理する。細かいデザイン判断はClaudeに任せる（2026-10-12）。

## いまの仕組み（2026-10-12 公開済み）

`p/` のページは3タイプのどれかに分ける。CSSはこのフォルダで一元管理し、`scripts/apply_page_type.py` で各ページの `<head>` にインラインで差し込む。

| タイプ | 対象 | 形 |
|---|---|---|
| read（読ませる） | ブログ記事・レビュー記事・プライバシー・/about/ | 本文幅660px（約38字）の1段、本文16→17px、h2は左の縦線 |
| show（魅せる） | アプリ紹介・各種一覧・EVIDENCE | 幅1080px、大見出し、カード1→2→3列、PCは見出し左/中身右 |
| use（使う） | ブラウザツール・診断 | 見出し小さめ、操作部は `.sd-tool` の1枚パネル、PCは説明左/道具右 |

- ブレークポイントは 600px / 960px の2つだけ。左右余白 `--sd-g` は 16/24/32px
- 新しいページ: `python3 scripts/apply_page_type.py {read|show|use} p/…/index.html`
- CSSを直したら: `python3 scripts/apply_page_type.py --refresh`
- 対象外: トップページ `p/index.html`（固定）と Flutter SPA
- AIからの信頼: `/about/`（運営者情報・編集方針）を全ページのフッターからリンク。JSON-LD の `publisher` に `"@id":"https://seadice.win/#organization"`

## これからの設計（おすすめ順）

1. **ヘッダー・フッターを全ページ共通にする** — 今は「SEADICE Tools」「ツール一覧」「ホームへ戻る」など表記がばらばら。ロゴ＋「読む／使う／アプリ」の3入口に揃える。デザインと同じ注入方式で一括適用できる
2. **ページの中身の並び順を型にする**（使うページ32枚から着手）
   - 読ませる: 結論1文 → 要点3つ → 本文 → 出典 → 今日できる一歩（ツール・アプリ）→ 更新日・運営者
   - 魅せる: 誰のどんな悩みか（Before→After）→ できること3つ → もとになった研究 → 画面 → 入手ボタン
   - 使う: ツール本体 → 結果の読み方 → 根拠と出典 → よくある質問
3. **中身の薄いページを整理する** — アプリ紹介254枚、検索に出さない設定のページが282枚。公開済みアプリは厚くし、未公開・終了はまとめるか検索から外すかをページごとに決める
4. **更新日と出典をどのページでも同じ位置に出す** — 2の型と一緒にやる
5. **ページ同士のつなぎ方** — 困りごと別の入口から「読む → 使う → アプリ」へ1本の道でつなぐ
6. **タイプ別の速度・見やすさチェック** — 代表ページで Lighthouse を測り、全ページ100点を保つ
